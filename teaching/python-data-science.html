Q1.Which Python library is primarily used for numerical computing with multi-dimensional arrays?
  • pandas
  • NumPy
  • Matplotlib
  • requests
Explanation: NumPy provides the ndarray object and vectorised operations — the foundation that pandas, scikit-learn, and most numerical libraries build on.
Q2.In pandas, which method gives a quick summary of numeric columns (count, mean, std, quartiles)?
  • df.info()
  • df.describe()
  • df.head()
  • df.summary()
Explanation: describe() returns count, mean, std, min, 25/50/75 percentiles, and max for numeric columns. info() shows dtypes and non-null counts.

A Python list is a heterogeneous, dynamically-typed container of Python objects — flexible but slow for numerical work. A NumPy array is a contiguous block of memory holding elements of a single fixed dtype (e.g., float64), which enables vectorised C-level operations. Arithmetic on arrays operates element-wise without Python loops, making it 10-100× faster than equivalent list code.

The standard pipeline has six phases: (1) Problem framing — what question are you answering? (2) Data collection — APIs, databases, CSVs, scraping. (3) Cleaning & preprocessing — missing values, dtypes, outliers, normalisation. (4) Exploratory Data Analysis (EDA) — distributions, correlations, visualisation. (5) Modelling — feature engineering, train/validate/test, hyperparameter tuning. (6) Communication — dashboards, reports, deployment. Iterate between phases as you learn more about the data.

.loc selects by label (the actual index value or column name) and is inclusive on both ends of a slice: df.loc[2:5] includes row labelled 5. .iloc selects by integer position (0-based) and is exclusive at the end like normal Python slicing: df.iloc[2:5] returns rows at positions 2, 3, 4. Use .loc when working with named indices, .iloc when working with positions.
