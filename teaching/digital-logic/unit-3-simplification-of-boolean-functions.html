Canonical forms: minterms and maxterms

SOP/POS is formally in Unit 3 (3.2). Use this as a bridge so Unit 3 starts smoothly.

1. The core concept: what makes a form "canonical"?

In digital logic, expressions can be written in many ways, but canonical forms provide a strict, standardized blueprint.

Canonical formEvery single variable (n variables) must appear in every term, either in its normal or complemented form.
Standard formTerms can be shortened and contain fewer literals (e.g. xy + x'z), which is what we ultimately simplify.

2. Minterms vs. maxterms

For n variables there are 2ⁿ possible input combinations. Each combination maps to a unique minterm and maxterm.

Minterm (standard product, Σ)

An AND product of all n variables. A variable is primed (') if its bit is 0, unprimed if 1. Evaluates to 1 for only one specific row.

m₃ = A'BCfor A = 0, B = 1, C = 1
Maxterm (standard sum, Π)

An OR sum of all n variables. A variable is primed (') if its bit is 1, unprimed if 0. Evaluates to 0 for only one specific row.

M₃ = A + B' + C'0 only when A = 0, B = 1, C = 1
Key identity: a minterm and its corresponding maxterm are exact complements of each other: mⱼ' = Mⱼ. Check with DeMorgan: (A'BC)' = A + B' + C' = M₃.

3. Where do the index numbers come from? (Σ and Π)

The numbers inside the shorthand notation (such as 1, 3, 6, 7) are the decimal equivalents of the truth table's binary row indices.

  • Sum of minterms (Σ): OR the minterms where F = 1. F = Σ(1, 3, 6, 7) means m₁ + m₃ + m₆ + m₇.
  • Product of maxterms (Π): AND the maxterms where F = 0. F = Π(0, 2, 4, 5) means M₀ · M₂ · M₄ · M₅.
4. Step-by-step example

Expand F = A + B'C to a sum of minterms (variables A, B, C)

  1. Term A is missing B and C. Multiply by (B + B') and (C + C'), which both equal 1:

    A = A(B + B')(C + C') = ABC + ABC' + AB'C + AB'C'

  2. Term B'C is missing A. Multiply by (A + A'):

    B'C = B'C(A + A') = AB'C + A'B'C

  3. OR everything together. AB'C appears twice; x + x = x removes the duplicate.

    F = A'B'C + AB'C' + AB'C + ABC' + ABC

  4. Write the index numbers: 001, 100, 101, 110, 111.

    F = Σ(1, 4, 5, 6, 7)

5. Quick conversion trick

If you have the minterm list, the maxterm list is instant: list the missing index numbers from 0 to 2ⁿ − 1. With 3 variables and F = Σ(1, 4, 5, 6, 7), the missing indices are 0, 2, 3, so F = Π(0, 2, 3).

The two canonical forms usually have many literals. Standard forms (sum of products such as y' + xy + x'yz', product of sums such as x(y' + z)(x' + y + z' + w)) allow terms with fewer literals. Simplifying them is the subject of Unit 3.

Syllabus 3.1

K-Map: two, three and four variable maps

3.1 3.1.1 · Text §3-1

Why the map method?

Every literal in an expression becomes a gate input, and every product term becomes a gate. A truth table has exactly one form, but the algebra for the same function can be long or short. The shorter one is the cheaper, faster circuit.

The goal of this unit: find an expression in sum of products (SOP) or product of sums (POS) with the fewest literals. The answer is not always unique.

Algebraic simplification works, but it has no rule telling you what to do next. The map method (Veitch diagram, modified by Karnaugh, so "K-map") turns that guesswork into a visual procedure: each square is one minterm, and a function is the area covered by its 1-squares.

Each K-map square is one minterm. Which product term is the square for m₆ of F(x, y, z)?

3.1 3.1.2 · Text §3-2

The two-variable map

Two variables give four minterms, so the map has four squares. Rows carry x (0 then 1), columns carry y. Mark a 1 in every square whose minterm belongs to the function.

First pattern to notice: a whole row or column of 1s collapses to a single variable. Two 1s side by side differ in exactly one variable, and that variable drops out: x'y + xy = y(x' + x) = y.

A 2-variable map has 1s in m₀ and m₁ only. What is F?

3.1 3.1.5 · Text §3-3

Prime and essential prime implicants

When solving Karnaugh maps (K-maps), things can get messy if you just circle groups by guesswork. Using Prime Implicants (PIs) and Essential Prime Implicants (EPIs) turns the process into a systematic, foolproof puzzle.

1. Prime Implicant (PI): The "As Big As Possible" Rule
What it is: A group of 1s that cannot be made any larger by combining it with adjacent groups.
In plain language: When you circle a group of 1s on a K-map, you always want it to be as big as the rules allow (1, 2, 4, 8, or 16 cells). If you've drawn a group of 2, but it could actually be expanded into a group of 4, that group of 2 is not a Prime Implicant.
The Goal: Before doing anything else, you must identify all possible PIs on the map. These represent all the candidate building blocks for your simplest expression.

2. Essential Prime Implicant (EPI): The "Mandatory Choice"
What it is: A Prime Implicant that is the only group covering at least one specific 1 on the map.
In plain language: Look closely at your 1s. Is there a 1 that is so isolated, or on an edge/corner, that only one single PI box covers it? That means that specific 1 has no other backup options.
The Rule: Essentials must always appear in your final minimal answer. If you leave an EPI out, your final boolean expression will be wrong because at least one 1 will be left uncovered.

Step-by-Step Strategy for Solving a K-Map: When you look at a four-variable K-map, follow this exact workflow:

  1. Find All Prime Implicants: Draw every single valid, maximum-size group of 1s (remembering that the map wraps around the edges like a globe). Don't worry about overlapping yet; just find all the biggest possible boxes.
  2. Spot the Essentials (EPIs): Scan every 1 on the map. Find any 1 that belongs to only one box. Circle those boxes—they are your Essential Prime Implicants. Lock them into your final answer right away.
  3. Cover the Rest: Look to see if all the 1s on the map are already covered by your EPIs.
    • If yes: You are done! Your final answer is just the sum of your EPIs.
    • If no: (some 1s are left out), pick the cheapest, simplest remaining PIs to cover the leftover 1s.
Worked example · Fig. 3-11

F(A, B, C, D) = Σ(0, 2, 3, 5, 7, 8, 9, 10, 11, 13, 15)

  1. Plot the eleven 1s.

  2. Essentials. m₀ fits in only one group of four, the corners: B'D'. m₅ fits only in the centre square m₅ m₇ m₁₃ m₁₅: BD. Both are essential and cover eight 1s.

  3. Remaining: m₃, m₉, m₁₁. m₃ is covered by CD or B'C; m₉ by AD or AB'; m₁₁ by any of the four.

  4. Pick one for m₃ and one for m₉. Four equally minimal answers, 8 literals each:

    F = BD + B'D' + CD + AD
    F = BD + B'D' + CD + AB'
    F = BD + B'D' + B'C + AD
    F = BD + B'D' + B'C + AB'

Syllabus 3.2

Product of sums, sum of products

3.2 3.2.1 · Text §3-5

Sum of products from the 1s

Every simplification in 3.1 produced a sum of products: each group of 1s is an AND term, and the terms are ORed. In hardware that is a two-level AND-OR circuit: one AND gate per term, one OR gate to collect them (inputs are assumed available in true and complemented form, so no inverters).

Worked example · Ex 3-8 (a)

F(A, B, C, D) = Σ(0, 1, 2, 5, 8, 9, 10) in SOP

  1. Group the 1s. Corners → B'D'; top and bottom rows, left columns → B'C'; m₁ m₅ → A'C'D.

  2. F = B'D' + B'C' + A'C'D

    AND-OR, two levels (Fig. 3-15a).

3.2 3.2.2 · Text §3-5

Product of sums from the 0s

The squares without 1s are the minterms of F'. Fill them with 0s and group the 0s exactly as you grouped 1s. That gives F' in SOP form. Complement it with DeMorgan's theorem (take the dual, complement each literal) and F appears in product-of-sums form.

Recipe: group 0s → write F' as SOP → complement → F as POS. The circuit is two-level OR-AND.
Worked example · Ex 3-8 (b)

Same F = Σ(0, 1, 2, 5, 8, 9, 10), now in POS

  1. Group the 0s: row 11 → AB; column 11 → CD; m₄ m₆ m₁₂ m₁₄ → BD'.

    F' = AB + CD + BD'

  2. Complement with DeMorgan: each product term becomes a sum term with every literal complemented.

    F = (AB + CD + BD')' = (A' + B')(C' + D')(B' + D)
  3. F = (A' + B')(C' + D')(B' + D)

    OR-AND, two levels (Fig. 3-15b).

3.2 3.2.3 · Text §3-5

Putting a POS function on the map

A function given as Π(maxterms) goes straight on the map: 0s in the listed squares, 1s everywhere else. A function given as a product of sums is entered through its complement: F' is a sum of products, and its terms mark the 0s.

Worked example · Text p. 87

Enter F = (A' + B' + C')(B + D), then simplify both ways

  1. Complement: F' = ABC + B'D'.

  2. Mark 0s for F': ABC → m₁₄, m₁₅. B'D' → the corners m₀, m₂, m₈, m₁₀. Every other square is 1.

  3. SOP from the 1s: rows 01 → A'B; m₁ m₃ m₉ m₁₁ → B'D; m₄ m₅ m₁₂ m₁₃ → BC'.

  4. The POS was already minimal (the 0s group exactly as B'D' and ABC). The same function has two minimal forms of different cost: SOP uses 6 literals, POS uses 5.

    F = A'B + B'D + BC' = (A' + B' + C')(B + D)

Simplification for NAND and NOR implementation

3.3 3.3.1 · Text §3-6

Why NAND and NOR, and their two symbols

Real ICs are built mostly from NAND and NOR gates: they are easier to fabricate and are the basic gates of every IC logic family. So a simplified expression has to be converted. Two pictures make the conversion painless.

Bubble rule: a small circle means complement. Two bubbles on the same line cancel, so they can be removed without changing the logic.

A NAND gate drawn as invert-OR computes which expression for inputs A, B?

3.3 3.3.2 · Text §3-6

NAND implementation (from SOP)

Start from AND-OR. Replace every AND with a NAND and the OR with a NAND drawn as invert-OR. The bubbles at the AND outputs meet the bubbles at the OR inputs and cancel, so the circuit is unchanged.

NAND rule: 1. simplify to SOP; 2. one NAND per product term (first level); 3. one NAND for the OR (second level); 4. a single-literal term needs an inverter, or feed its complement straight into the second level.
Worked example · Ex 3-9

Implement F(x, y, z) = Σ(0, 6) with NAND gates

  1. Map it. The two 1s are not adjacent, so SOP stays at two full minterms.

    F = x'y'z' + xyz'

  2. NAND-NAND straight from SOP (2 levels).

  3. Second way: combine the 0s for F' = x'y + xy' + z and build F' in NAND-NAND. To get F, add a one-input NAND at the output: three levels. Useful when the complement is wanted.

Before drawing a two-level NAND circuit for F, what form must F be in?

3.3 3.3.3 · Text §3-6

NOR implementation (from POS)

NOR is the dual of NAND, so every rule is the dual. Start from OR-AND: replace each OR with a NOR and the AND with a NOR drawn as invert-AND. The bubbles cancel again.

NOR rule: simplify to POS (combine 0s, complement); one NOR per sum term; one NOR at the second level; a single literal needs an inverter or its complement fed directly.
Worked example · Ex 3-10

Implement F(x, y, z) = Σ(0, 6) with NOR gates

  1. Group the 0s: F' = x'y + xy' + z.

  2. Complement for POS: F = (x + y')(x' + y)z'.

  3. NOR-NOR (2 levels). The single literal z' gets a one-input NOR, or feed z directly into the output gate.

    3.1 Uses O2 Board exam 2025 · Q(b)

    Exam 2025: simplify with don't-cares

    Question. Simplify the following using K-map:
    F(A, B, C, D) = Σ(0, 2, 4, 7, 10, 12)
    d(A, B, C, D) = Σ(1, 3, 5, 6, 8)

    The printed question uses ε; read it as Σ (sum of minterms). F lists the squares that must be 1, d lists the don't-care squares (X). Everything else (m₉, m₁₁, m₁₃, m₁₄, m₁₅) is 0. Don't-cares are optional topic O2; read that section first if X squares are new.

    Model answer · step by step

    F = Σ(0, 2, 4, 7, 10, 12), d = Σ(1, 3, 5, 6, 8)

    1. Draw the 4-variable map with rows AB and columns CD in Gray order (00, 01, 11, 10). Put 1 in squares 0, 2, 4, 7, 10, 12; X in 1, 3, 5, 6, 8; 0 in the rest.

    2. Biggest group first. The top two rows (A = 0) hold only 1s and Xs: m₀ m₂ m₄ m₇ plus X₁ X₃ X₅ X₆. Treat those four Xs as 1 and you get an octet → A'. One literal covers four real 1s, including the awkward m₇.

    3. m₁₂ is still uncovered. Column CD = 00 is m₀ m₄ m₁₂ X₈, a quad → C'D'.

      m₁₀ is still uncovered. The four corners are m₀ m₂ X₈ m₁₀, a quad because the edges wrap → B'D'.

    4. Check. Every 1 is covered: m₀ m₂ m₄ m₇ (A'), m₁₂ (C'D'), m₁₀ (B'D'). No group contains a 0. All three groups are essential prime implicants, because each holds a 1 that no other group can reach.

      GroupSquaresXs usedTerm
      Octet0, 1, 2, 3, 4, 5, 6, 71, 3, 5, 6A'
      Quad (column)0, 4, 8, 128C'D'
      Quad (corners)0, 2, 8, 108B'D'
    5. F = A' + B'D' + C'D'

      Two AND gates, one 3-input OR gate. A' goes straight to the OR gate. Factored form: F = A' + D'(B' + C').

      Bonus (POS, from the 0s). Group the 0s: m₉ m₁₁ m₁₃ m₁₅ → AD; m₁₄ m₁₅ → ABC. So F' = AD + ABC and F = (A' + D')(A' + B' + C'). Same 5 literals.

    How to write it in the exam
    1. Write F = Σm(0, 2, 4, 7, 10, 12) + d(1, 3, 5, 6, 8) and draw the map with labelled rows and columns.
    2. Fill 1s, Xs and 0s, then loop the octet and the two quads, naming each loop beside the map.
    3. State which Xs you took as 1 (1, 3, 5, 6, 8) and give F = A' + B'D' + C'D'.
    4. If the question asks for a circuit, draw the AND-OR diagram above.

    Optional O2 · Text §3-8

    Don't-care conditions

    Some input combinations never happen. A BCD digit uses only 10 of the 16 four-bit codes, so the other six are free. Mark those squares with X. While grouping, treat each X as a 1 if it makes a group bigger, and as a 0 otherwise. You never have to cover an X.

    Worked example · Ex 3-12

    F(w, x, y, z) = Σ(1, 3, 7, 11, 15), d = Σ(0, 2, 5)

    1. Plot 1s and Xs.

    2. Column 11 gives yz (m₃ m₇ m₁₁ m₁₅). Only m₁ is left. On its own with m₃ it would be w'x'z (3 literals). Use X's to make a group of four instead.

    3. Option (a): take X₀ and X₂ → top row → w'x'.

      Option (b): take X₅ → m₁ m₃ m₅ m₇ → w'z.

    4. Both are correct; they differ only in the value given to don't-care squares. For POS, combine 0s with X₀ and X₂: F' = z' + wy'.

      F = yz + w'x' or F = yz + w'z or F = z(w' + y)

    After grouping, one X square is not in any group. What should you do?

    The five-variable map

    Thirty-two squares, drawn as two 4-variable maps: A = 0 on the left (m₀–m₁₅), A = 1 on the right (m₁₆–m₃₁). Each half keeps its own adjacency, and a square is also adjacent to the square in the same position on the other half. Picture the two halves stacked on top of each other.

    Worked example · Ex 3-7

    F(A, B, C, D, E) = Σ(0, 2, 4, 6, 9, 13, 21, 23, 25, 29, 31)

    1. Plot. Six 1s fall in the A = 0 half, five in the A = 1 half.

    2. Inside A = 0: m₀ m₂ m₄ m₆ form a block of four → A'B'E' (A' is needed because the block lives only in the left half).

    3. Across both halves: column DE = 01, bottom two rows: m₉ m₁₃ (A = 0) sit over m₂₅ m₂₉ (A = 1). Four adjacent squares → BD'E; A drops out.

    4. Inside A = 1: m₂₁ m₂₃ m₂₉ m₃₁ → ACE.

    5. F = A'B'E' + BD'E + ACE

    Other two-level implementations

    With four gate types (AND, OR, NAND, NOR) in two levels there are 16 combinations. Eight are degenerate: they collapse to one operation (AND feeding AND is just a bigger AND). The other eight are nondegenerate and can realise any function.

    FormDualFunction performed
    AND-OROR-ANDSOP / POS
    NAND-NANDNOR-NORSOP / POS
    NOR-ORNAND-ANDOR-AND-INVERT / AND-OR-INVERT
    OR-NANDAND-NOROR-AND-INVERT / AND-OR-INVERT

    Wired logic: tying open-collector TTL NAND outputs together forms a wired-AND: F = (AB)'·(CD)' = (AB + CD)', an AND-OR-INVERT. ECL NOR outputs tied together form a wired-OR: F = [(A + B)(C + D)]', an OR-AND-INVERT.

    Worked example · Ex 3-11

    F(x, y, z) = Σ(0, 6) in all four AOI / OAI forms

    1. Combine 0s: F' = x'y + xy' + z, so F = (x'y + xy' + z)'. This is AND-OR-INVERT: build it as AND-NOR, or NAND-AND (z needs a one-input NAND there).

    2. Combine 1s: F = x'y'z' + xyz'. Complement: F' = (x + y + z)(x' + y' + z).

    3. So F = [(x + y + z)(x' + y' + z)]', an OR-AND-INVERT: build it as OR-NAND or NOR-OR.

    Optional O5 · Text §3-9 to 3-11

    The tabulation (Quine–McCluskey) method

    Maps rely on your eyes, and beyond five or six variables eyes fail. Tabulation is the same idea written as an algorithm a computer can run: combine minterms that differ in one bit, repeat until nothing combines, then pick a minimal set from what is left.

    Worked example · Ex 3-13

    F = Σ(0, 1, 2, 8, 10, 11, 14, 15)

    1. Group by number of 1s. Only neighbouring groups can differ by one bit, so you only compare a group with the one below it.

      1sMinterms (wxyz)
      00 = 0000
      11 = 0001, 2 = 0010, 8 = 1000
      210 = 1010
      311 = 1011, 14 = 1110
      415 = 1111

    2. Combine pairs differing in one bit; write a dash for the eliminated variable and tick the parents. Example: 0 (0000) + 1 (0001) → 000-. In decimal: two minterms combine when the lower group's number is larger by a power of 2.

      PairwxyzPairwxyz
      0,1000- ✗ no further match10,11101- ✓
      0,200-0 ✓10,141-10 ✓
      0,8-000 ✓11,151-11 ✓
      2,10 / 8,10-010 / 10-0 ✓14,15111- ✓

    3. Combine again (dashes must line up): 0,2,8,10 → -0-0; 10,11,14,15 → 1-1-. No further merges.

    4. Unticked terms are the prime implicants: 000- = w'x'y', -0-0 = x'z', 1-1- = wy.

      F = w'x'y' + x'z' + wy
