Syllabus 6.1

Sequential and combinational circuits

In Units 4 and 5 every circuit was combinational: its outputs depend only on the inputs present now. Most real systems also need memory. A sequential circuit is a combinational circuit plus memory elements connected in a feedback path. The bits stored in the memory elements at any time are the state of the circuit.

The outputs depend on the external inputs and the present state. The next state also depends on the inputs and the present state. So a sequential circuit is described by a time sequence of inputs, outputs and internal states.

Combinational circuitSequential circuit
Output depends only on present inputsOutput depends on present inputs and the present state (past inputs)
No memoryHas memory elements (flip-flops)
No feedback pathFeedback from memory to the combinational part
Described by a truth tableDescribed by a state table or state diagram
No clock neededUsually clocked (synchronous)
Adder, decoder, MUX, comparatorFlip-flops, registers, counters

Synchronous and asynchronous

  • Synchronous: behaviour is defined by its signals at discrete instants of time. A master-clock generator produces a periodic train of clock pulses, and memory elements change only when a clock pulse arrives. Such circuits are called clocked sequential circuits; they are free of instability and are the kind studied in this unit.
  • Asynchronous: behaviour depends on the order in which inputs change, at any instant. Memory comes from gate delays, and the feedback can make the circuit unstable.

The memory elements of clocked sequential circuits are flip-flops. A flip-flop stores one bit and has two outputs: the normal value Q and its complement Q′.

Check your understanding · 6.1

Q1State two differences between combinational and sequential circuits.Answer

A combinational circuit's output depends only on present inputs and it has no memory. A sequential circuit's output depends on present inputs and on the stored state, and it contains memory elements with feedback.

Q2Why are clocked (synchronous) circuits preferred?Answer

All flip-flops change only at clock pulses, so timing splits into independent discrete steps that can be analysed one at a time, and the instability problems of asynchronous feedback do not occur.

Syllabus 6.2

Flip-flops: RS, D, JK, T and master-slave

A flip-flop keeps its binary state as long as power is applied, until an input tells it to change. Flip-flop types differ in their inputs and in how those inputs affect the state. Each is described by:

  • a characteristic table: next state Q(t+1) for every present state Q(t) and input,
  • a characteristic equation: Q(t+1) as a Boolean function, read from a K-map of that table,
  • a graphic symbol, and, for design, an excitation table.

Two states: set (Q = 1, Q′ = 0) and reset/clear (Q = 0, Q′ = 1).

Basic flip-flop circuit (SR latch)

Two NOR gates (or two NAND gates) with each output fed back to the other gate's input. Because of this feedback the basic circuit is itself an asynchronous sequential circuit; all other flip-flops are built from it.

NOR version (Mano Fig. 6-2). Inputs normally 0. A momentary 1 on S sets Q = 1; a momentary 1 on R resets Q = 0. When the input returns to 0 the state is remembered. S = R = 1 forces Q = Q′ = 0, which is not allowed.

RS flip-flop (clocked)

Mano Fig. 6-4: a NAND basic flip-flop plus two NAND gates (3 and 4) controlled by the clock pulse CP. While CP = 0, gates 3 and 4 output 1 and nothing changes. While CP = 1, S and R reach the basic flip-flop.

Characteristic table (Mano Fig. 6-4b)

Characteristic equation

Q(t+1) = S + R′Q, with SR = 0

The two indeterminate rows (S = R = 1) are X's on the map, and the condition SR = 0 must be part of the equation. This indeterminate case makes the RS flip-flop hard to use, but it is the building block of all the others.

D flip-flop

Mano Fig. 6-5. D goes to S and its complement to R, so S and R can never both be 1. While CP = 1 the output follows D; when CP returns to 0 the last value of D is held. Also called a gated D-latch; "D" for data.

Characteristic table (Mano Fig. 6-5b)

Characteristic equation

Q(t+1) = D

The next state equals D whatever the present state. A D flip-flop has no "no change" input combination.

JK flip-flop

A refinement of RS: J acts as set and K as reset, and J = K = 1 complements (toggles) the state instead of being indeterminate. Mano Fig. 6-6 uses two cross-coupled NOR gates and two AND gates. Q is fed back to the K-gate and Q′ to the J-gate, so a pulse can only clear a set flip-flop or set a clear one.

Race problem. Set J = K = 1 and hold CP = 1: because of the feedback, the output keeps complementing for as long as the pulse lasts. See the race-around condition below the tables.

Characteristic table (Mano Fig. 6-6b)

Characteristic equation

Q(t+1) = JQ′ + K′Q

Race-around condition (J = K = 1)

The JK flip-flop above is level-triggered: it responds for the whole time CP = 1. Set J = K = 1 and apply one clock pulse:

  1. CP goes to 1. With J = K = 1 the flip-flop complements, and Q changes after one propagation delay Δt.
  2. The new Q and Q′ are fed back to the input AND gates. CP is still 1, so the gates see the new values and the flip-flop complements again after another Δt.
  3. This repeats for as long as CP stays 1: Q oscillates 0 → 1 → 0 → 1 …, about tp ÷ Δt times, where tp is the pulse width.
  4. When CP returns to 0 the oscillation stops, and Q is left at whatever value it had at that instant: 0 or 1, unpredictable.

The output "races around" the feedback loop several times in one pulse instead of toggling once. This is the race-around condition. It happens because tp > Δt, and it occurs only in the toggle case: with JK = 00, 01 or 10 a second pass through the loop changes nothing.

How to avoid it. (1) Make the pulse narrower than the propagation delay: tp < Δt < T (T = clock period). This is hard to guarantee because Δt varies from chip to chip and with temperature. (2) Use a master-slave JK flip-flop: the master changes during CP = 1 and the slave (the output) only when CP returns to 0, so the new Q cannot reach the inputs within the same pulse. (3) Use an edge-triggered flip-flop, which responds only at the clock edge. Real JK flip-flops use (2) or (3).

T flip-flop

A single-input JK flip-flop: J and K tied together as T (Mano Fig. 6-7). "T" for toggle: T = 0 keeps the state, T = 1 complements it at each clock pulse. It has the same race problem as the JK and the same remedy.

Triggering of flip-flops

A momentary change of an input that switches a flip-flop is a trigger. Clocked flip-flops are triggered by pulses. A positive pulse goes 0 → 1 (the positive edge) and back 1 → 0 (the negative edge).

The flip-flops above respond to the level of CP: they change as soon as CP reaches 1 and keep responding while it stays 1. In a sequential circuit the flip-flop outputs feed back through gates to flip-flop inputs. If an output changes while the clock is still 1, the new value can reach another flip-flop's input in the same pulse and cause a second, unwanted change. The cure is to make the flip-flop change only at a clock edge: a master-slave or an edge-triggered flip-flop.

Master-slave flip-flop

Two flip-flops in series: a master and a slave, with the clock inverted to the slave (Mano Fig. 6-9).

  • CP = 1: the master is enabled and follows the inputs (its output is Y). The slave is disabled, so Q does not change.
  • CP returns to 0: the master is disabled, so input changes no longer matter. The slave is enabled and copies the master: Q = Y.

So the output changes only at the negative edge of the pulse, and an output that feeds another flip-flop cannot affect it during the same pulse. In the JK master-slave flip-flop (Mano Fig. 6-11, nine NAND gates) the slave's Q and Q′ are fed back to the master's input gates; the master captures J and K on the positive edge and the slave takes the result on the negative edge, which removes the race for J = K = 1.

Try it: set the inputs, raise CP and watch the master (Y) change while Q waits, then lower CP and watch Q copy Y. Change the inputs while CP = 0 and nothing happens.

Optional · beyond syllabus

Edge-triggered D flip-flop

Mano Fig. 6-12 builds a positive-edge-triggered D flip-flop from three NAND basic flip-flops (six gates). Gates 1–4 produce internal signals S and R for the output latch (gates 5, 6):

  • CP = 0: S = R = 1, so the output holds, whatever D is.
  • At the positive edge: if D = 1, S goes to 0 and Q becomes 1; if D = 0, R goes to 0 and Q becomes 0.
  • While CP stays 1, changes in D are locked out; the negative edge has no effect.

D must be stable for a setup time before the edge and a hold time after it. In graphic symbols a small triangle (dynamic indicator) on the clock input means edge-triggered; a bubble before it means the negative edge.

Flip-flop excitation tables

The characteristic table answers "given the inputs, what is the next state?" (used in analysis). In design we know the transition we want, Q(t) → Q(t+1), and need the inputs that cause it. That reverse table is the excitation table (Mano Table 6-10). In simple terms it answers one question: "My flip-flop is in this state now. What inputs must I apply so that it goes to the state I want after the next clock pulse?"

  • Q(t) (present state): the output now, 0 or 1.
  • Q(t+1) (next state): the output we want after the next clock pulse, 0 or 1.
  • S, R, J, K, D, T (inputs): the values that must be applied to each type of flip-flop to make that transition happen.
  • X (don't-care): the input may be 0 or 1. The flip-flop reaches the required next state either way.
Q(t)Q(t+1)SRJKDT
000X0X00
01101X11
1001X101
11X0X010

Row by row

  • Row 1 · stay at 0 (0 → 0).
    • RS / JK: the set input must be off (S = 0, J = 0). The reset input does not matter (R = X, K = X): resetting a 0 leaves it at 0, and so does "no change".
    • D: the D flip-flop copies its input, so to get 0 next we apply D = 0.
    • T: T = 1 would change the state; we want no change, so T = 0.
  • Row 2 · change from 0 to 1 (0 → 1).
    • RS / JK: the set input must be on (S = 1, J = 1). For RS, R must be 0, because S = R = 1 is not allowed. For JK, K = X: K = 0 sets it, and K = 1 toggles 0 to 1, which also gives 1.
    • D: we want 1 next, so D = 1.
    • T: the state changes, so T = 1.
  • Row 3 · change from 1 to 0 (1 → 0).
    • RS / JK: the reset input must be on (R = 1, K = 1). For RS, S must be 0. For JK, J = X: J = 0 resets it, and J = 1 toggles 1 to 0, which also gives 0.
    • D: we want 0 next, so D = 0.
    • T: the state changes, so T = 1.
  • Row 4 · stay at 1 (1 → 1).
    • RS / JK: the reset input must be off (R = 0, K = 0). The set input does not matter (S = X, J = X): setting a 1 leaves it at 1, and so does "no change".
    • D: we want 1 next, so D = 1.
    • T: no change, so T = 0.

Key takeaways

  • D is the easiest: the D column is an exact copy of the Q(t+1) column. What you want next is what you apply.
  • T is a change detector: T = 1 only when the state changes (0 → 1 or 1 → 0), so T = Q(t) ⊕ Q(t+1).
  • RS and JK have X entries because two different input combinations produce the same transition. In design these X's become don't-cares in the K-maps, which gives simpler input equations. JK has an X in every row, which is why it usually gives the simplest circuit.

Check your understanding · 6.2

Q1Why is the input S = R = 1 not allowed in an RS flip-flop?Answer

Both outputs are forced to the same value (0 for NOR, 1 for NAND), so Q′ is no longer the complement of Q. When the inputs return to normal, the final state depends on which gate is faster: it is indeterminate.

Q2How does the JK flip-flop remove the RS restriction?Answer

Q is ANDed into the K gate and Q′ into the J gate. With J = K = 1 only the gate whose fed-back output is 1 passes the pulse, so the flip-flop is complemented instead of receiving set and reset together.

Q3A JK flip-flop has Q = 1. Give Q after a pulse for JK = 00, 01, 10, 11.Answer

00 → 1 (no change), 01 → 0 (reset), 10 → 1 (set), 11 → 0 (complement).

Q4Show that connecting T to the D input through an XOR with Q makes a T flip-flop.Mano 6-18

D = T ⊕ Q, and for a D flip-flop Q(t+1) = D = T ⊕ Q = TQ′ + T′Q, which is the T characteristic equation.

Q5Why does a master-slave flip-flop avoid the race problem?Answer

The master accepts inputs only while CP = 1, and the slave (the visible output) changes only when CP returns to 0, after the master has been isolated. A change at the output can therefore never reach the master during the same pulse.

Q6Write the excitation entries of a T flip-flop for the transition 1 → 0, and of an RS for 1 → 1.Answer

T: 1 → 0 needs T = 1 (complement). RS: 1 → 1 needs R = 0 and S = X.

Design with state equations and state reduction

To design a sequential circuit we first need the tools that describe one: state equations, the state table and the state diagram. They are introduced here by analysing a given circuit (Mano Section 6-4), then used in reverse for design.

State equation, state table and state diagram

Example circuit (Mano Fig. 6-16): two D flip-flops A and B, one input x, one output y. From the gates feeding the flip-flops, the flip-flop input functions are DA = Ax + Bx, DB = A′x and the output is y = (A + B)x′.

Mano Fig. 6-16 · Example of a sequential circuit (redrawn). Small grey labels show the signal on each gate output.

The state diagram shows the same information as a picture: a circle per state, and an arrow per transition labelled input/output. The arrow from 00 to 01 marked 1/0 means: in state 00 with x = 1 the output is 0, and the next clock pulse moves the circuit to 01. Step through it below.

Optional · beyond syllabus

Mealy and Moore models

  • Mealy model: outputs depend on the present state and the inputs. Example: Fig. 6-16, y = (A + B)x′. Arrows are labelled input/output.
  • Moore model: outputs depend on the present state only. Example: Fig. 6-19, where the flip-flop states are the outputs. Arrows carry only the input.

Moore outputs change only with the clock. Mealy outputs can change whenever an input changes, so the inputs should be synchronised with the clock and the outputs sampled only at the clock transition.

State reduction

Design aims to minimise flip-flops and gates. State reduction lowers the number of states in a state table while keeping the external input-output behaviour the same. It applies when only the output sequences matter, not the state names (so states are written as letters, not binary values).

Rule (Mano): Two states are equivalent if, for each input, they give exactly the same output and send the circuit to the same state or to an equivalent state. One of two equivalent states can be removed.

Example (Mano Fig. 6-21, Table 6-5): seven states a–g, input x, output y.

Step 0. State table (Table 6-5)

Step 1. e and g both go to a / f with outputs 0 / 1, so g ≡ e. Remove row g and write e wherever g appears.

Step 2. Now f goes to e / f with outputs 0 / 1, the same as d, so f ≡ d. Remove f, replace by d. No more equal rows: reduced table (Table 6-7).

The reduced circuit has 5 states instead of 7 and gives the same output for any input sequence. Check it with any sequence; Mano's example is 01010110100.

Fewer states does not always mean fewer flip-flops: 7 and 5 states both need 3 flip-flops (2³ = 8). But the 3 unused states become don't-cares, which usually simplifies the gates.

Check your understanding · 6.3

Q1What is a state equation, and why is it easy to write for D flip-flops?Answer

It gives the next state of a flip-flop as a Boolean function of the present state and inputs. For a D flip-flop Q(t+1) = D, so the state equation is just the D input function.

Q2How many rows does the state table of a circuit with 3 flip-flops and 2 inputs have?Answer

2^(3+2) = 32 rows.

Q3In the reduced table, why can f be replaced by d only after g has been replaced by e?Answer

Originally f went to g on x = 0 and d went to e. They were only equivalent if g ≡ e. Once g is replaced by e, f's row reads e, f / 0, 1, the same as d's row after f → d, so they are equivalent.

Q4Why do JK designs usually need fewer gates than RS or D designs?Answer

Every row of the JK excitation table has one don't-care, so half of every J and K map is X, which allows large groups and simple functions.

Q5Design the circuit of Fig. 6-23 with T flip-flops.Mano 6-24

T = 1 where the bit changes. From the state table: TA = Σ(2, 7), TB = Σ(1, 2, 5, 7) over (A, B, x).

TA = A′Bx′ + ABx = B(A ⊕ x)′, TB = B′x + Ax + A′Bx′.

6-6D flip-flops A, B; inputs x, y; output z. A(t+1) = x′y + xA, B(t+1) = x′B + xA, z = B. Derive the state table.Answer

Read across: with x = 0 the circuit loads A from y and holds B; with x = 1 both flip-flops take the value of A.

6-10A JN flip-flop: J acts like the J of a JK, and N = K′. Give its characteristic and excitation tables and show that tying J and N together gives a D flip-flop.Answer

Characteristic: JN = 00 → 0 (reset, since K = 1); 01 → Q (no change); 10 → Q′ (complement); 11 → 1 (set).

Excitation: 0→0: J = 0, N = X · 0→1: J = 1, N = X · 1→0: J = X, N = 0 · 1→1: J = X, N = 1.

J = N = D: D = 0 gives row 00 → 0; D = 1 gives row 11 → 1. So Q(t+1) = D.

6-14Reduce the state table: a: f, b / 0, 0; b: d, c / 0, 0; c: f, e / 0, 0; d: g, a / 1, 0; e: d, c / 0, 0; f: f, b / 1, 1; g: g, h / 0, 1; h: g, a / 1, 0.Answer

b and e have identical rows → e ≡ b. d and h are identical → h ≡ d. After replacing e by b, c's row is f, b / 0, 0, the same as a → c ≡ a.

Reduced table (5 states): a: f, b / 0, 0 · b: d, a / 0, 0 · d: g, a / 1, 0 · f: f, b / 1, 1 · g: g, d / 0, 1.

6-15Starting from state a of Problem 6-14, find the output sequence for input 01110010011.Answer

States: a f b c e d g h g g h (a). Outputs: 0 1 0 0 0 1 1 1 0 1 0. Problem 6-16 (the reduced table) gives the same output sequence. Try it in the state-reduction runner by entering the table mentally, or check one step at a time.

6-20Design with two D flip-flops A, B and input x: x = 0 holds the state; x = 1 steps 00 → 01 → 11 → 10 → 00.Answer
  1. State table. 00: x0 → 00, x1 → 01 · 01: 01, 11 · 10: 10, 00 · 11: 11, 10.
  2. Flip-flops. Two D flip-flops A, B.
  3. State equations. DA = Σ(3, 4, 6, 7), DB = Σ(1, 2, 3, 6) over (A, B, x).
  4. Simplified. DA = Ax′ + Bx, DB = A′x + Bx′.
  5. Logic diagram. Four AND gates and two OR gates feeding the D inputs.
6-23Design the circuit of Fig. 6-23 with RS flip-flops.Answer

Use the RS excitation table on each transition. A: 0→0 (S0 R X) rows 000, 001, 011; 0→1 row 010; 1→1 rows 100, 101, 110; 1→0 row 111. B: 0→0 rows 000, 100; 0→1 rows 001, 101; 1→0 rows 010, 111; 1→1 rows 011, 110.

Maps over (A, B, x): SA = Σ(2) + d(4, 5, 6), RA = Σ(7) + d(0, 1, 3), SB = Σ(1, 5) + d(3, 6), RB = Σ(2, 7) + d(0, 4).

SA = Bx′, RA = Bx, SB = B′x, RB = A′x′ + ABx. Check: no row has S = R = 1.
