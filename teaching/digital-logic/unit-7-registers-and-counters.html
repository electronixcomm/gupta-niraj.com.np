Syllabus 7.1

Introduction

A circuit made only of flip-flops is still a sequential circuit, even with no gates. Some MSI circuits that contain flip-flops are named after the job they do rather than called "sequential circuits". The two most important are registers and counters.

  • Register: a group of flip-flops, each storing one bit. An n-bit register has n flip-flops and stores any n-bit word. It may also contain gates that control when and how new data enters.
  • Counter: a register that goes through a predetermined sequence of states when input pulses are applied. The gates are connected so that the flip-flops step through the sequence (for example 0, 1, 2, …, 15).
  • Memory unit: a large collection of storage cells with the circuits to read and write them (optional section at the end).

Registers hold operands and results, shift registers convert between serial and parallel data, and counters generate the timing signals that sequence the operations of a digital system.

The 4-bit register

The simplest register is just four D flip-flops with a common clock (Mano Fig. 7-1). One clock pulse transfers the four inputs I4…I1 into the flip-flops at the same time, and the outputs A4…A1 can be read at any time.

Mano Fig. 7-1 · 4-bit register (redrawn).

Register with parallel load

Transferring new information into a register is called loading. Loading all bits with one clock pulse is a parallel load. In a real system the master clock runs all the time, so the register needs a Load control that decides which pulses have an effect:

  • Load = 1: the inputs I4…I1 are loaded on the next clock pulse.
  • Load = 0: each D input is fed back from its own output, so the clock pulse reloads the present value and the register is unchanged. The feedback is needed because a D flip-flop has no "no change" input.
  • Clear (asynchronous) resets all flip-flops to 0 without a clock pulse.

So each flip-flop has Di = Load·Ii + Load′·Ai: a 2-to-1 multiplexer in front of every D input (Mano Fig. 7-3).

Optional · beyond syllabus

Sequential circuit = register + combinational circuit

Any clocked sequential circuit can be drawn as a register (the flip-flops) plus a combinational circuit that computes the next state and the outputs (Mano Fig. 7-4). The combinational part can be SSI gates, a ROM or a PLA, so the design reduces to a combinational design.

Example 7-1/7-2. State table: A1(t+1) = Σ(4, 6), A2(t+1) = Σ(1, 2, 5, 6), y = Σ(3, 7) over (A1, A2, x). With gates: A1(t+1) = A1x′, A2(t+1) = A2 ⊕ x, y = A2x. With a ROM: 3 address inputs (A1, A2, x) and 3 outputs (next A1, next A2, y), so an 8 × 3 ROM whose truth table is exactly the state table.

Check your understanding · 7.1

Q1How many flip-flops does a register need to store the decimal number 200 in binary?Answer

200 = 110010002, 8 bits, so an 8-bit register (8 flip-flops).

Q2Why does a register with parallel load built from D flip-flops need a feedback path from each output?Answer

A D flip-flop always copies D on every clock pulse; it has no "no change" input. With Load = 0 the D input must therefore receive the flip-flop's own output, so each pulse reloads the same value.

Q3What is the difference between a latch and a register (Mano)?Answer

A group of flip-flops sensitive to the pulse duration (gated latches) is called a latch; a group sensitive to the pulse transition (edge-triggered or master-slave) is called a register.

Syllabus 7.2

Left and right shift registers

A register that can move its bits one position to the right or to the left is a shift register. It is a chain of flip-flops in cascade: the output of each flip-flop drives the input of the next, and all flip-flops share one clock, so every pulse moves every bit one place (Mano Fig. 7-7).

  • Serial input (SI): the bit that enters the first flip-flop on each pulse.
  • Serial output (SO): the output of the last flip-flop, the bit that leaves.

Shift right: SI enters the leftmost flip-flop, data moves left → right

Shift left: SI enters the rightmost flip-flop, data moves right → left

The two circuits are the same chain: turn the shift-right register upside-down and it shifts left. A register that shifts in one direction only is unidirectional. The register of Fig. 7-7 shifts on the negative edge of every pulse (small circle on the clock input).

Shifting and arithmetic. For an unsigned binary number, a shift left with 0 entering multiplies by 2 (0110 = 6 → 1100 = 12); a shift right with 0 entering divides by 2 and drops the remainder (0110 = 6 → 0011 = 3).

Bidirectional shift register with parallel load

A register that can shift both ways is bidirectional. If it can also load in parallel it is a shift register with parallel load (sometimes called a universal shift register). Mano Fig. 7-9 builds one from four D flip-flops and four 4 × 1 multiplexers: the mode inputs s1s0 select what each D input receives.

Optional · beyond syllabus

Serial transfer

In serial mode, data moves one bit per clock pulse. To copy register A into register B, connect SO of A to SI of B, and SO of A also back to SI of A so that A keeps its data (it circulates). A shift-control signal ANDed with the clock lets exactly four pulses T1…T4 through (one word time; the time for one bit is the bit time). Mano Fig. 7-8, Table 7-1, with A = 1011 and B = 0010:

After four pulses both registers hold 1011: A has been copied into B and A is unchanged. Serial operation is slower than parallel (one pulse per bit instead of one pulse per word) but needs less hardware.

Optional · beyond syllabus

Serial addition

Two numbers in shift registers A and B are added one bit pair per pulse with a single full adder and a carry flip-flop (Mano Fig. 7-10). On each pulse the FA adds the two serial outputs and the stored carry; the sum bit is shifted into A (A ends up holding the sum) and the carry-out is stored in the flip-flop for the next pair. A parallel adder needs n full adders; the serial adder needs one full adder and one flip-flop, so it is a sequential circuit.

Designed as a sequential circuit with a JK carry flip-flop Q (Mano Table 7-3): JQ = xy, KQ = x′y′ = (x + y)′, S = x ⊕ y ⊕ Q.

Q1A 4-bit shift-right register holds 1101. Serial input bits 0, 1, 1 are applied with three clock pulses. Give the content after each pulse and the serial output bits.Answer

1101 → 0110 (out 1) → 1011 (out 0) → 1101 (out 1). Each pulse: the new bit enters on the left, the rightmost bit leaves.

Q2The register 0011 (= 3) is shifted left twice with 0 entering. What is the result in decimal?Answer

0011 → 0110 → 1100 = 12 = 3 × 2 × 2. Each left shift multiplies by 2 (as long as no 1 is lost from the left end).

Q3In the bidirectional register of Fig. 7-9, what must s1s0 be to keep the content while clock pulses continue?Answer

00: every MUX selects input 0, the flip-flop's own output, so each pulse reloads the same value.

Why a SISO register is useful although its output equals its input: it delays the data by n clock periods (n = number of stages), so it is a digital delay line and temporary store. PISO lets many parallel lines share one serial line (to a computer or over a communication link); SIPO does the reverse at the receiving end.

Check your understanding · 7.3

Q1How many clock pulses are needed to load an 8-bit word into a SIPO register, and how many to read it out?Answer

8 pulses to shift the word in; none to read it, because all 8 outputs are available in parallel.

Q2Which mode converts data from a keyboard's serial line into a byte for the CPU, and which converts a CPU byte for a serial transmission line?Answer

Receiving: SIPO (serial → parallel). Transmitting: PISO (parallel → serial).

Q3A 4-bit SISO register is cleared and the data 1011 is fed in, LSB first. After how many pulses does the first data bit appear at the serial output?Answer

After the 4th pulse the first bit (1) has passed through all four stages and sits in the last flip-flop. The whole word has left after 7 pulses (4 + 3).

Q4Why does a PIPO register have no connections between its flip-flops?Answer

No bit ever moves from one flip-flop to another: each input goes straight into its own flip-flop on the clock pulse, so no shifting path is needed.

Syllabus 7.4

Asynchronous and synchronous counters

MSI counters come in two kinds:

  • Asynchronous (ripple) counter: only the first flip-flop receives the count pulses. Every other flip-flop is clocked by the output transition of the previous flip-flop, so the flip-flops change one after another.
  • Synchronous counter: the count pulses go to the clock inputs of all flip-flops, so they all change at the same moment. Gates on the J, K (or T) inputs decide which flip-flops toggle.

A counter with n flip-flops that goes through 2n states is a mod-2n counter (4 flip-flops: mod-16, counts 0 to 15).

Binary ripple counter

A chain of complementing flip-flops (JK with J = K = 1, or T with T = 1). Count pulses drive the clock of A1 (the least significant bit); the output of each flip-flop drives the clock of the next higher one (Mano Fig. 7-12). The small circle on each clock input means the flip-flop complements on the negative edge, when the signal at its clock goes 1 → 0.

  • A1 complements on every count pulse.
  • Every time A1 goes 1 → 0 it complements A2; every time A2 goes 1 → 0 it complements A3; and so on.

Example, 0111 → 1000: the pulse complements A1 (1 → 0), which complements A2 (1 → 0), which complements A3 (1 → 0), which complements A4 (0 → 1). A4's 0 → 1 change would not trigger a further stage. The change travels through the counter like a ripple, which gives the counter its name.

Synchronous binary counter

All clock inputs are tied to the common count pulse CP. The rule for counting up in binary decides which flip-flops toggle:

  • The lowest bit A1 complements on every pulse: J1 = K1 = 1 (or = Count enable).
  • Any other bit complements only when all lower bits are 1, because those bits are about to roll over to 0: J2 = K2 = A1, J3 = K3 = A1A2, J4 = K4 = A1A2A3.

Example: present state 0011. A1 toggles (always), A2 toggles (A1 = 1), A3 toggles (A2A1 = 11), A4 does not (A3A2A1 = 011). Next state 0100. Mano Fig. 7-17 builds this with a chain of AND gates; the last AND gate gives a carry to the next 4-bit stage.

Synchronous up-down counter

Counting down, a bit complements when all lower bits are 0 (they are about to become 1s). Example: 1100 → 1011: A1 always, A2 because A1 = 0, A3 because A2A1 = 00, not A4 because A3A2A1 = 100. So the down counter is Fig. 7-17 with the AND gates fed from Q′ instead of Q.

Mano Fig. 7-18 combines both with T flip-flops and an Up and a Down control. With Ti for stage i:

T1 = Up + Up′·Down
Ti = Up·(A1…Ai−1) + Up′·Down·(A′1…A′i−1)

Up = 1 counts up (Up has priority if both are 1); Up = 0, Down = 1 counts down; both 0 holds the count. The live synchronous counter above has an Up/Down selector so you can try it.

Check your understanding · 7.4

Q1A 4-bit ripple counter uses flip-flops with tpd = 20 ns. What is the worst-case settling time and the maximum safe count frequency?Answer

Worst case all four stages change (e.g. 0111 → 1000): 4 × 20 = 80 ns. fmax ≈ 1 / 80 ns = 12.5 MHz.

Q2In a 4-bit synchronous binary up counter the present state is 1011. Which flip-flops toggle and what is the next state?Answer

A1 toggles (always); A2 toggles (A1 = 1); A3 toggles (A2A1 = 11); A4 does not (A3A2A1 = 011, not all 1s). Next state 1011 → 1100 (11 → 12).

Q3How many flip-flops are needed for a counter that counts 0 to 100?Answer

101 states; 26 = 64 < 101 ≤ 128 = 27, so 7 flip-flops.

Syllabus 7.5

Asynchronous up and down counters

A down counter decrements by 1 on every pulse: a 4-bit down counter goes 15, 14, 13, …, 1, 0, 15, … Looking at the down sequence, the lowest bit still complements on every pulse, but each other bit complements when the bit below it goes 0 → 1 (not 1 → 0 as in the up counter). Mano gives three ways to get a ripple down counter:

  1. Use the up counter of Fig. 7-12 but take the outputs from the Q′ terminals.
  2. Keep the outputs at Q but use positive-edge triggered flip-flops (no circles), so each stage complements when the previous Q goes 0 → 1.
  3. Keep negative-edge flip-flops and connect each clock input to the Q′ output of the previous flip-flop: when Q goes 0 → 1, Q′ goes 1 → 0 and triggers the next stage.

Caution. Changing M while the counter runs can produce a false clock edge at the selector output (for example Q = 1, Q′ = 0 and M switching from 1 to 0 makes CLK fall 1 → 0) and change the count by mistake. Change the mode only between pulses, or use a synchronous up/down counter.

Q1A 3-bit ripple down counter is at 100. List the next four states.Answer

Q2In a ripple down counter with negative-edge flip-flops, why is the next clock taken from Q′?Answer

Counting down, a stage must complement when the previous bit goes 0 → 1. At that moment Q′ goes 1 → 0, which is exactly the negative edge the next flip-flop responds to.

Syllabus 7.6

Decade counter and ring counter

BCD ripple counter (decade counter)

A decade (decimal) counter has ten states and returns to 0 after 9. It needs at least four flip-flops. Counting in BCD the sequence is 0000, 0001, …, 1001, 0000: like a binary counter, except that the state after 1001 is 0000 (Mano Fig. 7-13). The six states 1010 to 1111 are never used.

Mano Fig. 7-14 builds it from four negative-edge JK flip-flops named Q1, Q2, Q4, Q8 after their BCD weights:

Flip-flopClock inputJKCondition for its transition
Q1Count pulses11Complemented on the negative edge of every count pulse
Q2Q1Q′81When Q1 goes 1 → 0: complemented if Q8 = 0, cleared if Q8 = 1
Q4Q211Complemented when Q2 goes 1 → 0
Q8Q1Q4Q21When Q1 goes 1 → 0: complemented if Q4Q2 = 11, cleared otherwise

So from 0111 the next pulse makes Q8 = 1 (Q4Q2 = 11) while Q1, Q2, Q4 roll to 0: 1000. From 1001 the next pulse clears Q8 (Q4Q2 = 00) and Q2 stays 0 (J2 = Q′8 = 0, K2 = 1): 0000. A ripple counter is asynchronous, so it is explained by these conditions, not by state equations.

Cascading decades

To count 0 to 99 use two decade counters; 0 to 999 needs three (Mano Fig. 7-16). The clock of each higher decade comes from Q8 of the decade below: when that decade goes 9 → 0, its Q8 falls 1 → 0 and advances the next decade by one. The count after 399 is 400.

Optional · beyond syllabus

Synchronous BCD counter

A synchronous BCD counter does not follow the regular binary pattern, so it is designed with the Unit 6 procedure (Mano Table 7-5) using T flip-flops: T = 1 wherever a bit changes. States 1010–1111 are don't-cares. Output y = 1 in state 1001 enables the next decade.

TQ1 = 1 TQ2 = Q′8Q1 TQ4 = Q2Q1
TQ8 = Q8Q1 + Q4Q2Q1 y = Q8Q1

Four T flip-flops, five AND gates and one OR gate.

Ring counter

A ring counter is a circular shift register with exactly one flip-flop set and all others cleared. The serial output of the last flip-flop is fed back to the serial input of the first, so the single 1 circulates (Mano Fig. 7-22a).

  • A 4-bit ring counter preset to 1000 goes 1000 → 0100 → 0010 → 0001 → 1000. It has only n states with n flip-flops (mod-n), far fewer than the 2n of a binary counter.
  • Each output is 1 for exactly one clock period in four: the outputs are the timing signals T0, T1, T2, T3 with no decoding gates (Mano Fig. 7-22c).
  • It must be preset to a state with a single 1. Started from 0000 it stays at 0000 forever.
  • The same four timing signals can come from a 2-bit counter and a 2 × 4 decoder (Fig. 7-22b). For 2n signals: a ring counter needs 2n flip-flops; a counter + decoder needs n flip-flops and 2n n-input AND gates.
Optional · beyond syllabus

Johnson (switch-tail ring) counter

If the complement output of the last flip-flop is fed back to the first input, the register is a switch-tail ring counter. From 0000 it fills with 1s from the left, then with 0s: a k-bit switch-tail ring counter has 2k states (twice the ring counter). A Johnson counter is a k-bit switch-tail ring counter plus 2k two-input AND gates that decode the states into 2k timing signals (Mano Fig. 7-23).

Check your understanding · 7.6

Q1A BCD ripple counter is at 0111. Explain, flip-flop by flip-flop, why the next state is 1000.Answer

Q1 1 → 0 (every pulse). That edge clocks Q2 (J = Q′8 = 1, K = 1 → complement, 1 → 0) and Q8 (J = Q4Q2 = 11 → 1, K = 1 → complement, 0 → 1). Q2 1 → 0 clocks Q4 (complement, 1 → 0). Result Q8Q4Q2Q1 = 1000.

Q2How many flip-flops do a mod-8 ring counter and a mod-8 Johnson counter need?Answer

Ring: 8 (n states with n flip-flops). Johnson: 4 (2k states with k flip-flops).

Q3A three-decade BCD counter shows 299. What is the display after one more pulse, and which Q8 outputs fall?Answer

300. The units decade goes 9 → 0, its Q8 falls and clocks the tens decade, which also goes 9 → 0; its Q8 falls and clocks the hundreds decade 2 → 3.

Syllabus 7.7

Applications of counters

Mod-N counters

A mod-N counter goes through a repeated sequence of N states (a 4-bit binary counter is mod-16, a BCD counter mod-10). Two common ways to get any N:

  1. Asynchronous clear: a gate detects state N and clears the counter at once. Example decade counter: a NAND gate on Q8 and Q2 detects 1010 and clears to 0000. The state N appears only for a moment (a short spike), so Mano does not recommend it.
  2. Counter with parallel load (Mano Example 7-4): detect the last wanted state and load a starting value on the next clock pulse, so every state lasts a full clock period.

Mano Fig. 7-20 shows four ways to make a mod-6 counter from the 4-bit counter with parallel load (Fig. 7-19):

(a)AND gate detects 0101 (A3A1)Load inputs 0000 on the next pulse0, 1, 2, 3, 4, 5
(b)NAND gate detects 0110 (A3A2)Clear immediately (asynchronous)0, 1, 2, 3, 4, 5 (0110 flashes for an instant)
(c)Carry-out at 1111Load 101010, 11, 12, 13, 14, 15
(d)A4 = 1 (state 1000)Load 00113, 4, 5, 6, 7, 8

Timing sequences: word-time generation

The control unit of a digital system uses timing signals to decide when each operation happens. A serial system needs a word-time signal that stays 1 for as many clock pulses as there are bits in a word. Mano Fig. 7-21 uses a 3-bit counter for an 8-pulse word time:

  1. The counter is cleared. A one-clock Start pulse sets flip-flop Q; Q = 1 is the word-time signal and also enables the counter.
  2. The counter counts the clock pulses 0, 1, …, 7.
  3. At count 7 (111) an AND gate produces Stop, which goes to the R input of Q.
  4. The next pulse returns the counter to 000 and resets Q. Q stayed 1 for exactly 8 pulses; the counter is disabled until the next Start.

For parallel systems, a ring counter (or a counter plus decoder) gives one timing signal per clock period, see the ring counter.

Optional · beyond syllabus

Memory unit (random-access memory)

A memory unit is a collection of storage cells plus the circuits to move information in and out. Any word can be reached directly by its address, hence random-access memory (RAM). Information is stored in words of n bits.

  • n data input lines and n data output lines (one word).
  • k address lines select one of 2k words (addresses 0 to 2k − 1).
  • Control inputs: Read and Write (or Memory enable and Read/Write′).

Conventions: K = 210, M = 220, G = 230; so 64K = 216, 2M = 221, 4G = 232. A 1K × 16 memory has 1024 words of 16 bits (2048 bytes) and 10 address lines.

Write: put the address on the address lines, put the data on the data input lines, activate Write. Read: put the address on the address lines, activate Read; the word appears on the data output lines. Memory enable (chip select) = 0: no operation; = 1 with Read/Write′ = 0: write; = 1 with Read/Write′ = 1: read.

Check your understanding · 7.7

Q1A 4-bit ripple counter is driven by a 16 kHz clock. What is the frequency at each output?Answer

A1 = 8 kHz, A2 = 4 kHz, A3 = 2 kHz, A4 = 1 kHz (16 kHz ÷ 16).

Q2Which counters are needed for the "seconds" part of a digital clock?Answer

A mod-10 (decade) counter for the units digit followed by a mod-6 counter for the tens digit: together mod-60.

Q3In Fig. 7-21, why does the word-time signal last 8 pulses and not 7?Answer

Stop becomes 1 at count 7, but Q is only reset by the next clock pulse, the one that takes the counter from 111 back to 000. Q is therefore 1 during counts 0 to 7: eight pulses.

Exam practice

Problem bank

Exam-style problems on the whole unit, with worked answers.

P1Draw a 4-bit SIPO shift register with D flip-flops. Starting from 0000, the serial data 1, 1, 0, 1 is applied. Tabulate QA…QD after each pulse.Answer

Four D flip-flops in a chain: DATA → DA, QA → DB, QB → DC, QC → DD, common clock, all Q brought out.

Pulse 1: 1000 · Pulse 2: 1100 · Pulse 3: 0110 · Pulse 4: 1011. The first bit applied is now in QD.

P2Differentiate between asynchronous and synchronous counters (at least four points).Answer

(1) Clock: only the first flip-flop vs all flip-flops. (2) Speed: delay n·tpd vs one tpd; synchronous is faster. (3) Glitches: ripple has transient false states, synchronous does not. (4) Hardware: ripple needs no extra gates for binary counting; synchronous needs AND gates. (5) Design: ripple by reasoning about edges; synchronous by the state-table procedure.

P3Design a 3-bit synchronous binary up counter using JK flip-flops.Answer
  1. Sequence 000 → 001 → … → 111 → 000.
  2. Excitation: a bit toggles (J = K = 1) when all lower bits are 1, otherwise J = K = 0.
  3. Result: JA1 = KA1 = 1, JA2 = KA2 = A1, JA3 = KA3 = A1A2.
  4. Circuit: three JK flip-flops on a common clock and one AND gate.
P4Draw a 3-bit asynchronous down counter and its timing diagram. Start from 000.Answer

Three negative-edge JK flip-flops, J = K = 1; CP → A1; Q′1 → clock of A2; Q′2 → clock of A3.

Sequence: 000 → 111 → 110 → 101 → 100 → 011 → 010 → 001 → 000. A1 toggles on every falling CP edge; A2 toggles when A1 rises; A3 toggles when A2 rises (use the live counter in 7.4 set to Down to draw it).

P5Explain the BCD ripple counter of Mano Fig. 7-14 and draw its timing diagram for ten pulses.Answer

Use the four conditions in 7.6 (Q1 every pulse; Q2 on Q1↓ if Q8 = 0; Q4 on Q2↓; Q8 on Q1↓ set if Q4Q2 = 11, else cleared). Timing (Mano Fig. 7-15): Q1 0101010101 · Q2 0011001100 · Q4 0000111100 · Q8 0000000011, then all 0 after the 10th pulse.

P6What is a ring counter? Draw a 4-bit ring counter and give its states and timing signals. Why must it be preset?Answer

A circular shift register (last Q → first D) with a single 1 circulating. Preset 1000 → 0100 → 0010 → 0001 → 1000; outputs T0…T3 are each 1 for one clock period in four. From 0000 (or any state without exactly one 1) it would never reach the intended sequence, so it is preset with the direct set/clear inputs.

P7Design a mod-6 counter from a 4-bit binary counter with parallel load so that it counts 0 to 5.Answer

Count = 1, inputs I = 0000. An AND gate on A3 and A1 detects 0101 (the first state with both 1 in the 0–5 range) and drives Load. On the pulse after 5 the counter loads 0000. Sequence 0, 1, 2, 3, 4, 5, 0 … (Mano Fig. 7-20a).

P8How many timing signals can 4 flip-flops give as (a) a ring counter, (b) a Johnson counter, (c) a counter with decoder?Answer

(a) 4, no decoder. (b) 8, with eight 2-input AND gates. (c) 16, with a 4-to-16 decoder (sixteen 4-input AND gates).
