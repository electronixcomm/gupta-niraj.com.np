2.1 Introduction to Boolean algebra Core

Switching circuits

Let switch closed = 1, open = 0; lamp on = 1, off = 0.

Electronic digital circuits are called switching circuits because a transistor behaves like a switch: conducting (closed) or not conducting (open), controlled by binary signals (two voltage ranges standing for 0 and 1). The hardware blocks that perform AND, OR, NOT are called logic gates.

Start from what students already know (switches, true/false) and build towards a formal algebra.

Binary logic

Binary logic deals with binary variables (letters such as A, B, x, y) that take only two values, 0 and 1, and with logical operations. There are three basic operations:

AND (· or no symbol)
x · y = z or xy = z
z = 1 only if x = 1 and y = 1.
OR (+)
x + y = z
z = 1 if x = 1 or y = 1 (or both).
NOT (prime ' or overbar)
x' = z
z is the opposite of x.
DefinitionA truth table lists every possible combination of the input variables (2n rows for n variables) and the resulting output.
Common confusionBinary logic is not binary arithmetic. In arithmetic, 1 + 1 = 10 ("one plus one is two"); in logic, 1 + 1 = 1 ("one OR one is one").

From logic to an algebra

  • 1854: George Boole introduced a systematic algebra of logic, now called Boolean algebra.
  • 1938: Claude Shannon introduced two-valued switching algebra and showed it describes bistable switching circuits.
  • 1904: E. V. Huntington gave the postulates we use as the formal definition.

Designers use Boolean algebra to turn circuit diagrams into expressions and back, and to simplify circuits before building them.

Background: what an algebraic structure needs

Any deductive system starts from a set of elements, operators and postulates (unproved axioms). A binary operator * (here * is just a representational symbol, could be anything like + or ·) on set S assigns to each pair (a, b) a unique element c = a * b. Common postulates:

2.2 Basic theory and properties of Boolean algebra Core

Huntington postulates

Boolean algebra is an algebraic structure on a set B with two binary operators + and · such that:

#Postulate(a) for +(b) for ·
P1ClosureB is closed under + and ·
P2Identityx + 0 = xx · 1 = x
P3Commutativex + y = y + xx · y = y · x
P4DistributiveProduct-to-Sum

Numbering follows Mano. The supplementary notes number them differently (e.g. Distribution = P3, Identity = P4); tell students which scheme the exam uses.

How Boolean algebra differs from ordinary algebra

  1. The associative law is not a postulate, but it can be derived (Theorem 4).
  2. x + yz = (x + y)(x + z) holds in Boolean algebra, not in ordinary algebra.
  3. No additive or multiplicative inverses, so no subtraction or division.
  4. The complement operator has no counterpart in ordinary algebra.
  5. The two-valued Boolean algebra has only two elements: B = {0, 1}.
Common mistakeStudents "cancel" terms as in ordinary algebra. From x + y = x + z you cannot conclude y = z (try x = 1).

Two-valued Boolean algebra

B = {0, 1} with + as OR, · as AND and ' as NOT satisfies all six postulates. Closure, identity, commutativity and complement can be read directly from the operator tables. The distributive law is checked over all 8 combinations:

Columns x(y + z) and xy + xz agree in every row, so the law holds. Engineers call this algebra switching algebra, and from here on "Boolean algebra" means the two-valued one.

Duality Principle

Duality: The principle states that any valid Boolean algebraic identity remains true if you interchange its operators and identity elements while keeping all variables and their complements completely unchanged.

To find the dual of any expression, follow these exact rules:
  • Swap the operators: Replace every AND (·) with an OR (+), and every OR (+) with an AND (·).
  • Leave variables alone: Keep all variables and their complements (x, x', y, z', etc.) in their exact original form.
  • Swap constants (if present): Replace any 0 with 1, and any 1 with 0.
Example:
• Original: xx'yz' + x'y'z
• Dual: (x' + y + z') · (x' + y' + z)
Why Duality is Necessary & Its Implications:
  • Built-In Symmetry: Unlike arithmetic, Boolean algebra treats its primary operations (+ and ·) with equal structural weight.
  • The "Two-for-One" Rule: Every mathematical law or theorem comes in a mirrored pair; proving one automatically proves its dual, cutting axiom work in half.
  • Circuit Flexibility & Optimization: Enables engineers to seamlessly switch between Sum-of-Products (SOP) and Product-of-Sums (POS) hardware implementations depending on gate constraints.
  • Simplification Efficiency: Provides an alternative path to simplify an expression if its native form is too complex to reduce directly.
Expression Dual

x + x' = 1 x · x' = 0
x + xy = x x(x + y) = x

Algebraic Proof of De Morgan's Law: (x + y)' = x'y' (For advanced study)

The Big Picture: The "Uniqueness of the Complement" Trick
Normally, proving a De Morgan's law requires complex truth tables or long multi-step reductions. But in advanced Boolean algebra, there is a powerful shortcut rule: If you want to prove that expression B is the exact complement of expression A (meaning B = A'), you only need to prove two things:

  • A + B = 1 (When you OR them together, you get 1)
  • A · B = 0 (When you AND them together, you get 0)

For this proof, let A = (x + y) and B = x'y'. By showing that (x + y) + x'y' = 1 and (x + y) · x'y' = 0, we mathematically prove that x'y' must be the complement of (x + y), which means (x + y)' = x'y'.

Part 1: Proving the OR condition equals 1 (x + y) + x'y'= (x + y + x')(x + y + y')P4(b) (Distributive Law) = (y + 1)(x + 1)P3, P5(a) (Commutative & Complement) = 1 · 1 = 1Theorem 2(a) Part 2: Proving the AND condition equals 0 (x + y) · x'y'= xx'y' + yx'y'P4(a), P3 (Distributive Law) = 0 · y' + x' · 0P5(b) (Complement Law) = 0 + 0 = 0Theorem 2(b)

Conclusion: Because (x + y) and x'y' satisfy both rules (their sum is 1 and their product is 0), they form a strictly complementary pair. Therefore, (x + y)' = x'y' is proven true!

2.3 Boolean functions Core

DefinitionA Boolean function is an expression made of binary variables, the operators AND, OR, NOT, parentheses and an equals sign. For each input combination its value is 0 or 1.

Three ways to represent a function

1. Algebraic expression
F₁ = xyz' is 1 only when x = 1, y = 1, z = 0.
2. Truth table
2n rows, inputs counted 0 to 2n−1 in binary. Unique for each function.
3. Logic diagram
One gate per term, one input per literal, inverters for complemented variables.

F₁ = xyz', F₂ = x + y'z, F₃ = x'y'z + x'yz + xy', F₄ = xy' + x'z

Key questionF₃ and F₄ have identical columns, so they are the same function. A truth table is unique; an expression is not. Boolean algebra is mostly used to find the simplest expression for a given function.

Algebraic manipulation (literal minimisation)

LiteralA variable in primed or unprimed form. Each literal is a gate input and each term is a gate, so fewer literals and terms means less hardware.

There is no fixed algorithm; we try postulates and theorems ("cut and try"). Systematic methods (K-maps) come in Unit 3.

Why only eight standard gates?

A gate is worth building if it is cheap to make, extends to more than two inputs, has useful properties (commutative, associative) and can build other functions. Extending gates to multiple inputs

A gate extends to more inputs if its operation is commutative and associative. AND and OR have both: (x + y) + z = x + (y + z) = x + y + z.

Why Does This Let Us "Extend" Gates?

Because AND and OR are both associative and commutative, we can drop the parentheses entirely and write a multi-input expression simply as:
x + y + z or x.y.z

In hardware design, this means:

  • we can physically build a 3-input OR gate or an 8-input AND gate.
  • we don't need to worry about chaining multiple 2-input gates in a specific sequence or hierarchy just to combine several signals. Any combination or wiring order will yield the correct logical result.

Different Case: NAND and NOR are commutative but not associative:

hint: F₈ = (x + y)'   x ↓ y   NOR i.e. Not-OR


(x ↓ y) ↓ z = [(x + y)' + z]' = (x + y)z' = xz' + yz'
x ↓ (y ↓ z) = [x + (y + z)']' = x'(y + z) = x'y + x'z

With x = 1, y = 0, z = 0 the first gives 1 and the second gives 0. So multi-input NAND/NOR are defined as complemented AND/OR:

x ↓ y ↓ z = (x + y + z)'    x ↑ y ↑ z = (xyz)'

Cascaded NAND gates need careful parentheses:

XOR and XNOR are commutative and associative, so they extend too. A multi-input XOR is an odd function: output is 1 when an odd number of inputs are 1. In practice it is built by cascading 2-input gates.

O1 · Canonical forms: minterms and maxterms Optional · Unit 3 preview

SOP/POS is formally in Unit 3 (3.2). Use this as a bridge so Unit 3 starts smoothly.

1. The Core Concept: What Makes a Form "Canonical"?

In digital logic, expressions can be written in many ways, but canonical forms provide a strict, standardized blueprint:

  • Canonical Form: Every single variable (n variables) must appear in every term—either in its normal or complemented form.
  • Standard Form: Terms can be shortened and contain fewer literals (e.g., xy + x'z), which is what we ultimately simplify.

2. Minterms vs. Maxterms

For n variables, there are 2n possible input combinations. Each combination maps to a unique minterm and maxterm.

  • Minterm (Standard Product - Σ): An AND product of all n variables. A variable is primed (') if its bit is 0, and unprimed if 1. Evaluates to 1 for only one specific row (e.g., m3 = A'BC for A=0, B=1, C=1).
  • Maxterm (Standard Sum - Π): An OR sum of all n variables. A variable is primed (') if its bit is 1, and unprimed if 0. Evaluates to 0 for only one specific row (e.g., M3 = A + B' + C').

Key Identity: A minterm and its corresponding maxterm are exact complements of each other: mj' = Mj.

3. Where Do the Index Numbers Come From? (Σ and Π)

The numbers inside the shorthand notation (such as 1, 3, 6, 7) are the decimal equivalents of the truth table's binary row indices. Each input combination maps to a specific row number:

Index (j)Binary (ABC)Minterm (mj)Maxterm (Mj)
00 0 0A'B'C'A + B + C

............

  • Sum of Minterms (Σ): OR the minterms where F = 1. Compact notation: F = Σ(1, 3, 6, 7) means m1 + m3 + m6 + m7.
  • Product of Maxterms (Π): AND the maxterms where F = 0. Compact notation: F = Π(0, 2, 4, 5) means M0 · M2 · M4 · M5.

4. Step-by-Step Example: Expanding to Sum of Minterms

Expanding F = A + B'C for 3 variables (A, B, C):

5. Quick Conversion Trick

If you have the minterm list, finding the maxterm list is instant: just list the missing index numbers from 0 to 2n − 1.

Example: If 3 variables and F = Σ(1, 4, 5, 6, 7), the missing indices are 0, 2, 3. Therefore, the Product of Maxterms is F = Π(0, 2, 3).

The two canonical forms usually have many literals. Standard forms (sum of products such as y' + xy + x'yz', product of sums such as x(y' + z)(x' + y + z' + w)) allow terms with fewer literals. Simplifying them is the subject of Unit 3.

O3 · Characteristics of logic families Optional

Fan-in
Number of inputs to a gate. Often limited to 4–5 in fast technologies; larger gates are built from smaller ones (e.g. 7-input NAND from two 4-input NANDs and an inverter).
Fan-out
Number of standard loads a gate output can drive without degrading. A gate driving six inverters of 1.0 load each has fan-out 6.
Propagation delay
Time for a change at the input to reach the output, in ns. tPHL and tPLH are measured at the 50% point of the output. Often quoted as the average (tPHL + tPLH)/2; some texts use max(tPHL, tPLH).
Power dissipation
PD = VCC × ICC(avg), with ICC(avg) = (ICCH + ICCL)/2.
Noise margin
Largest noise voltage that does not change the output. NMH = VOH − VIH, NML = VIL − VOL.

Worked examples

O4 · Positive and negative logic Optional

A signal has a high level H and a low level L. Positive logic: H = 1, L = 0. Negative logic: L = 1, H = 0. The names refer to the assignment, not to the sign of the voltages.

Physical behaviour from the data sheet

Positive logic reading (H = 1): output is 1 only when both inputs are 1 → AND gate.

Negative logic reading (L = 1): output is 1 when either input is 1 → OR gate.

Changing polarity swaps all 0s and 1s at inputs and output, which gives the dual function: AND ↔ OR, NAND ↔ NOR. Negative-logic inputs/outputs are marked with a small triangle (polarity indicator). We assume positive logic throughout the course.

    SolutionF' = x'(yz)' = x'(y' + z').
    F·F' = (x + yz)x'(y' + z') = x'yz(y' + z') = x'yy'z + x'yzz' = 0.
    F + F' = x + yz + x'(y' + z') = x + yz + y' + z' = x + yz + (yz)' = 1 (using x + x'a = x + a).
  11. Find the complement of xy' + x'y.
    Solution(xy')'(x'y)' = (x' + y)(x + y') = x'y' + xy: the complement of XOR is XNOR.
  12. Find the complement of (AB' + C)D' + E.
    SolutionF' = [(AB' + C)D']'E' = [(AB' + C)' + D]E' = [(A' + B)C' + D]E'.
  13. Find the complement of F₁ = x'yz' + x'y'z by the dual method.
    SolutionDual: (x' + y + z')(x' + y' + z); complement each literal: F₁' = (x + y' + z)(x + y + z').
  14. Using DeMorgan, rewrite F = x'y' + x'z + y'z with only OR and NOT operations.
    Solutionx'y' = (x + y)', x'z = (x + z')', y'z = (y + z')', so F = (x + y)' + (x + z')' + (y + z')': only OR gates and inverters needed.
  15. Show that F = AB + CD can be implemented with NAND gates only.
    SolutionF = ((AB + CD)')' = ((AB)'(CD)')': two 2-input NANDs produce (AB)' and (CD)', and a third NAND combines them.
  16. Show that NOR is not associative.
    Solution(x ↓ y) ↓ z = xz' + yz', x ↓ (y ↓ z) = x'y + x'z. At x = 1, y = z = 0: the first is 1, the second is 0.
  17. Write the truth table of x ⊕ y ⊕ z and state when it is 1.
    SolutionF = 1 for rows 001, 010, 100, 111 (minterms 1, 2, 4, 7): an odd number of 1s. See the table in 2.4.

Optional problems (O1–O4)

  1. Express F(A,B,C) = A + B'C as a sum of minterms and a product of maxterms.
    SolutionΣ(1, 4, 5, 6, 7) = Π(0, 2, 3).
  2. Convert F(x,y,z) = Σ(1, 3, 7) to the other canonical form.
    SolutionΠ(0, 2, 4, 5, 6).
  3. A 14-pin TTL package has 12 pins for inputs and outputs. How many of each gate fit: (a) 2-input XOR (b) 3-input AND (c) 4-input NAND (d) 5-input NOR (e) 8-input NAND?
    SolutionPins per gate = inputs + 1. (a) 12/3 = 4 (b) 12/4 = 3 (c) 12/5 → 2 (d) 12/6 = 2 (e) 12/9 → 1.
  4. A gate has VOH = 4.4 V, VIH = 3.5 V, VIL = 1.5 V, VOL = 0.1 V. Find the noise margins.
    SolutionNMH = 4.4 − 3.5 = 0.9 V; NML = 1.5 − 0.1 = 1.4 V.
  5. Show that a positive-logic NAND gate is a negative-logic NOR gate.
    SolutionSwapping polarity complements every input and output, which gives the dual function. The dual of NAND, (xy)', is (x + y)' = NOR.

One-page summary

Postulates
x + 0 = x, x·1 = x
x + x' = 1, x·x' = 0
x(y + z) = xy + xz
x + yz = (x + y)(x + z)
Theorems
x + x = x, x·x = x
x + 1 = 1, x·0 = 0
(x')' = x
x + xy = x, x(x + y) = x
x + x'y = x + y
DeMorgan
(x + y)' = x'y'
(xy)' = x' + y'
Complement: swap +/·, complement every literal
Duality
Swap + ↔ · and 0 ↔ 1, keep literals unchanged
Precedence
( ) → NOT → AND → OR
Counts
n variables: 2n truth-table rows, 22ⁿ functions (16 for n = 2)
Gates
AND, OR, NOT, buffer, NAND, NOR, XOR, XNOR
Universal: NAND, NOR
Not associative: NAND, NOR
Multi-input XOR = odd function
XOR
x ⊕ y = xy' + x'y
x ⊙ y = xy + x'y' = (x ⊕ y)'
x ⊕ 0 = x, x ⊕ 1 = x'
