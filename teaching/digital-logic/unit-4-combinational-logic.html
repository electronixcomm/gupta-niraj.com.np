Combinational Logic

Using Boolean algebra and K-maps from Units 2 and 3 to design, analyse and build real circuits: adders, subtractors, code converters, and multilevel NAND/NOR networks.

Syllabus: 4.1 – 4.4Teaching: 8 hoursReference: M. Morris Mano, Ch. 4
4.1Design half/full adders and half/full subtractors from a word statement.
4.2Design a code converter using don't-cares; analyse a given circuit.
4.3Convert any AND-OR circuit to NAND-only and back.
4.4Do the same with NOR gates, using duality.

What makes a circuit "combinational"?

A combinational circuit is made only of logic gates. Its outputs at any instant depend only on the present inputs. It has no memory and no feedback path. A sequential circuit adds memory elements (flip-flops), so its outputs also depend on past inputs. Sequential circuits are covered in Unit 6.

With n inputs there are 2ⁿ input combinations, and each combination produces exactly one output combination. So a circuit with m outputs is completely described by m Boolean functions, or by one truth table with 2ⁿ rows.

CombinationalSequential
Output = f(present inputs)Output = f(present inputs, stored state)
Gates only, no feedbackGates + memory (flip-flops), has feedback
Described by a truth tableDescribed by a state table / time sequence
Adder, subtractor, code converter, MUX, decoderFlip-flops, registers, counters
Syllabus 4.1

Design procedure of adders and subtractors

The design procedure

Every combinational design in this unit follows the same six steps. Students should be able to write these from memory.

  1. State the problem.
  2. Determine the number of input and output variables.
  3. Assign letter symbols to the inputs and outputs.
  4. Derive the truth table that relates inputs to outputs.
  5. Obtain the simplified Boolean function for each output (algebra or K-map).
  6. Draw the logic diagram.

Input combinations that can never occur are don't-care conditions (X). They may be set to 0 or 1, whichever gives a simpler circuit. A practical design also weighs gate count, inputs per gate, propagation delay, number of interconnections and fan-out limits.

Every circuit in this unit is designed with these six steps, in this order. Each design below is laid out step by step so students can copy the same format into their exam answers.

Analysis procedure

Analysis is design in reverse: start from a logic diagram, end with Boolean functions, a truth table, or a description of what the circuit does. First confirm the circuit is combinational (no feedback, no memory). Then:

  1. Label every gate output that depends only on the inputs; write its function.
  2. Label gates fed by previously labelled gates; write their functions.
  3. Repeat until the circuit outputs are reached.
  4. Substitute back to express each output in terms of the inputs only.

To get the truth table directly, list the 2ⁿ input combinations, then fill in one column per labelled gate in the same order.

Step 1Gates fed by inputs only: AB, AC, BC, T₁ = A + B + C, T₂ = ABC
Step 2Gates fed by labelled gates: F₂ = AB + AC + BC, F₂′, T₃ = F₂′T₁
Step 3Repeat until the output: F₁ = T₃ + T₂
Step 4Substitute: F₁ = (AB + AC + BC)′(A + B + C) + ABC
= (A′ + B′C′)(AB′ + AC′ + BC′ + B′C) + ABC
= A′BC′ + A′B′C + AB′C′ + ABC

Step through the inputs below and fill in every gate column yourself, in the order the table lists them (inputs-only gates first) before looking at the table. Comparing with Section 4.1 shows the circuit is a full adder: F₁ is the sum and F₂ the carry.

Analysing don't-cares. The designer assumed the unused BCD inputs never occur, but if one is applied by mistake the circuit still produces an output, fixed by how the X's were grouped. For the BCD→Excess-3 converter, input 1010 gives wxyz = 1101. Set A B C D = 1 0 1 0 in the converter bench above to confirm.

Syllabus 4.3

Multilevel NAND circuits

Real circuits are usually built from NAND or NOR gates, because these are the cheapest and most common in IC form. Two-level NAND/NOR (Unit 3) handled SOP and POS. Here we handle any number of levels.

NAND is a universal gate

Any Boolean function can be built from NAND gates alone, because NOT, AND and OR can all be built from them:

Two graphic symbols for a NAND gate

By De Morgan's theorem, (ABC)′ = A′ + B′ + C′. So a NAND can be drawn as AND-invert (AND with an output bubble) or as invert-OR (OR with bubbles on the inputs). Toggle the inputs: the two outputs are always equal.

Procedure: AND-OR diagram to NAND diagram

  1. Draw the AND-OR-inverter diagram from the expression (assume both x and x′ are available).
  2. Replace every AND gate with a NAND drawn as AND-invert.
  3. Replace every OR gate with a NAND drawn as invert-OR.
  4. Check every bubble. Two bubbles on the same line cancel. For each uncompensated bubble, insert an inverter (one-input NAND) or complement the input literal.

Example 1 · F = A + (B′ + C)(D′ + BE′)

Four levels of gating. In the mixed-symbol diagram, the bubbles on inputs A, B′, C and D′ are uncompensated, so those literals are complemented to A′, B, C′ and D. All three diagrams below are driven by the same inputs: their outputs always agree. The NAND count equals the AND-OR count.

Example 2 · F = (CD + E)(A + B′)

Here the output gate is an AND, drawn as AND-invert, which leaves an uncompensated bubble at the output. One extra NAND (as an inverter) restores F. Inputs E, A and B′ are complemented. In general, NAND gates = AND-OR gates + an occasional inverter.

Analysis of a NAND diagram

Use the analysis procedure from 4.2, applying De Morgan's theorem at each gate. For Mano Fig. 4-14:

T₁ = (CD)′ = C′ + D′ T₂ = (BC′)′ = B′ + C
T₃ = (B′T₁)′ = (B′C′ + B′D′)′ = (B + C)(B + D) = B + CD
T₄ = (AT₃)′ = [A(B + CD)]′
F = (T₂T₄)′ = BC′ + A(B + CD)

The truth table (Table 4-3) is built column by column: T₁ and T₂ first, then T₃, T₄ and F. A K-map of F gives F = AB + BC′ + ACD, the same function.

Converting a NAND diagram to AND-OR. Change the symbol of the gates in alternate levels to invert-OR, starting from the output level. Remove pairs of bubbles on the same line. Remove a bubble on an input by complementing that input (B′ becomes B). The result can be read directly: F = BC′ + A(B + CD). The bench shows the NAND diagram and its AND-OR equivalent side by side.

Check your understanding · 4.3

Q1How many NAND gates are needed for NOT, AND and OR?Answer

NOT: 1 (one-input NAND). AND: 2 (NAND + inverter). OR: 3 (two inverters + NAND, since (A′B′)′ = A + B).

Q2Implement F = AB + CD with NAND gates only.Answer

Two-level: F = [(AB)′ · (CD)′]′. Three 2-input NAND gates.

Q3Draw a multilevel NAND circuit for F = w(x + y + z) + xyz.Mano 4-19(b)

AND-OR: OR(x,y,z) → AND with w → OR with AND(x,y,z). Converting, the first-level OR becomes invert-OR, so x, y, z are complemented:

F = NAND( NAND(w, NAND(x′,y′,z′)), NAND(x,y,z) ). Four NAND gates. Check: NAND(x′,y′,z′) = x + y + z.

Q4When converting NAND → AND-OR, which levels get the invert-OR symbol?Answer

Alternate levels, starting with the last (output) level. Then the bubbles pair up along lines and cancel.

Q5Why does the NAND version sometimes need one more gate than the AND-OR version?Answer

If a bubble is left uncompensated at the output (as in Example 2, where the last gate is an AND), an inverter must be added to restore the true output. Bubbles on inputs are absorbed by complementing literals, provided both x and x′ are available.

Syllabus 4.4

Multilevel NOR circuits

NOR is the dual of NAND. Every rule for NAND logic has a NOR version obtained by swapping AND ↔ OR. NOR is also universal.

NOR is a universal gate

NOT is a one-input NOR. OR needs two NOR gates (NOR + inverter). AND needs three, since (A′ + B′)′ = AB.

Two graphic symbols for a NOR gate

OR-invert and invert-AND are the same gate, because (A + B + C)′ = A′B′C′.

Procedure: AND-OR diagram to NOR diagram

  1. Draw the AND-OR diagram from the expression (assume both x and x′ are available).
  2. Replace every OR gate with a NOR drawn as OR-invert.
  3. Replace every AND gate with a NOR drawn as invert-AND.
  4. For any bubble not compensated by another bubble on the same line, insert an inverter or complement the input literal.

Example · F = (AB + E)(C + D)

The first-level AND has input bubbles on A and B, so they become A′ and B′. Every other bubble pairs up. The NOR count equals the AND-OR count.

Analysis of a NOR diagram

Same procedure: label gate outputs and substitute. A typical NOR output T = (A + B′ + C)′ = A′BC′ is 1 only when ABC = 010, so its truth-table column is quick to fill.

To convert NOR → AND-OR, change the symbol to invert-AND in alternate levels starting from the output, cancel bubble pairs, and complement inputs that keep a bubble. For Mano Fig. 4-20:

F = [(C + D)B′ + A](B + C′) = (A + C + D)(A + B′)(B + C′)

Supporting topic · Mano §4-9

Exclusive-OR and parity

XOR appears in every adder and subtractor above, so it is worth a short lesson of its own. x ⊕ y = xy′ + x′y is 1 when exactly one input is 1. Its complement, XNOR (equivalence), is (x ⊕ y)′ = xy + x′y′.

x ⊕ 0 = x x ⊕ 1 = x′ x ⊕ x = 0 x ⊕ x′ = 1
x ⊕ y′ = x′ ⊕ y = (x ⊕ y)′ A ⊕ B = B ⊕ A (A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)

XOR built from four NAND gates: the first NAND gives (xy)′ = x′ + y′, and the remaining two levels give (x′ + y′)x + (x′ + y′)y = xy′ + x′y.

Odd function and parity

For three or more variables, XOR equals 1 when an odd number of inputs are 1: A ⊕ B ⊕ C = Σ(1, 2, 4, 7). It is called the odd function; its complement is the even function.

An even-parity generator adds bit P so that the total number of 1s is even: P = x ⊕ y ⊕ z. The parity checker at the receiver computes C = x ⊕ y ⊕ z ⊕ P. C = 1 flags an error (an odd number of 1s arrived).

Tying the checker's P input to 0 turns it into a generator, since z ⊕ 0 = z. The same circuit can do both jobs.

  5. Simplified functions. B₃ = G₃, B₂ = G₃ ⊕ G₂, B₁ = G₃ ⊕ G₂ ⊕ G₁, B₀ = G₃ ⊕ G₂ ⊕ G₁ ⊕ G₀.
  6. Logic diagram. A chain of three XOR gates: B₂ = B₃ ⊕ G₂, B₁ = B₂ ⊕ G₁, B₀ = B₁ ⊕ G₀.

4-4Design a circuit that adds 1 to a 4-bit number A₃A₂A₁A₀ using four half adders.Answer
  1. Problem. Add 1 to a 4-bit binary number (incrementer).
  2. Inputs and outputs. 4 inputs, 4 outputs (plus a carry-out for overflow).
  3. Symbols. Inputs A₃ A₂ A₁ A₀; outputs S₃ S₂ S₁ S₀, carry C₄.
  4. Truth table. Output = input + 1. Example rows: 0000→0001, 0111→1000, 1101→1110, 1111→0000 with C₄ = 1.

4-5A circuit forms the binary sum of two 2-bit numbers x₁x₀ and y₁y₀. Outputs C, S₁, S₀.Answer
  1. Problem. Add two 2-bit binary numbers.
  2. Inputs and outputs. 4 inputs, 3 outputs (largest sum 3 + 3 = 6 = 110₂).
  3. Symbols. Inputs x₁ x₀, y₁ y₀; outputs C S₁ S₀.
  4. Truth table. 16 rows, output = x₁x₀ + y₁y₀. Example rows: 00+00 = 000, 01+01 = 010, 10+11 = 101, 11+11 = 110.
  5. Simplified functions. S₀ = x₀ ⊕ y₀, S₁ = x₁ ⊕ y₁ ⊕ x₀y₀, C = x₁y₁ + x₀y₀(x₁ + y₁).
  6. Logic diagram. A half adder for bit 0 and a full adder for bit 1, with the half adder's carry as the full adder's carry-in (this is also problem 4-6).
4-7Multiply two 2-bit numbers a₁a₀ × b₁b₀ to give c₃c₂c₁c₀, using AND gates and half adders.Answer

  2. Inputs and outputs. 4 inputs, 4 outputs (largest product 3 × 3 = 9 = 1001₂).
  3. Symbols. Inputs a₁ a₀, b₁ b₀; outputs c₃ c₂ c₁ c₀.
  4. Truth table. 16 rows, output = a × b. Example rows: 10 × 11 = 0110, 11 × 11 = 1001, 01 × 10 = 0010.
  5. Simplified functions. c₀ = a₀b₀, c₁ = a₁b₀ ⊕ a₀b₁, c₂ = a₁b₁ ⊕ a₁a₀b₁b₀, c₃ = a₁a₀b₁b₀.

4-11Four inputs, four outputs: the output is the 2's complement of the input.Answer
  1. Problem. Output the 2's complement of a 4-bit binary number.
  2. Inputs and outputs. 4 inputs, 4 outputs.
  3. Symbols. Inputs A B C D; outputs w x y z.
  4. Truth table. 16 rows, output = (16 − N) mod 16. Example rows: 0000→0000, 0001→1111, 0110→1010, 1000→1000, 1111→0001.
  5. Simplified functions. z = D, y = C ⊕ D, x = B ⊕ (C + D), w = A ⊕ (B + C + D).
  6. Logic diagram. Two OR gates (C + D, then B + C + D) and three XOR gates; z is a direct wire from D.
4-17Analyse the two-output circuit of Fig. P4-17 and explain its operation.Answer

F₂ = AB + C(A + B) = AB + AC + BC. F₁ = F₂′(A + B + C) + ABC, which expands to A′B′C + A′BC′ + AB′C′ + ABC = A ⊕ B ⊕ C. So the circuit is a full adder: F₁ is the sum and F₂ the carry. It is the same circuit as the analysis bench in 4.2, drawn differently.

4-20Convert the BCD→Excess-3 logic diagram (Fig. 4-8) to a multilevel NAND circuit.Approach

Apply the four-step procedure. AND gates become AND-invert NANDs, OR gates become invert-OR NANDs. The OR gates for y, x and w are at the output level and their inputs come from AND-invert gates, so those bubbles cancel. The inverter feeding y, (C + D)′, and the OR gate C + D need care: the OR at the first level becomes invert-OR with complemented inputs C′, D′. Wherever a bubble is left uncompensated (for example where C + D also feeds an AND directly), insert a one-input NAND. Check your answer in the converter bench by comparing outputs for all ten BCD inputs.

4-30Rewrite AB′CD′ + A′BCD′ + AB′C′D + A′BC′D using only XOR and AND gates.Answer

Factor: (AB′ + A′B)(CD′ + C′D) = (A ⊕ B)(C ⊕ D). Two XOR gates and one AND gate.
