Topics queued: cloud service models (IaaS/PaaS/SaaS), regions vs. availability zones, Azure storage tiers, IAM/RBAC.

IaaS (Infrastructure-as-a-Service) gives raw compute, storage, and networking — you manage the OS and runtime (e.g., Azure VMs). PaaS (Platform-as-a-Service) abstracts the OS away and gives you a managed runtime (e.g., Azure App Service). SaaS (Software-as-a-Service) delivers a complete end-user application (e.g., Microsoft 365). The further up the stack, the less you manage and the less control you have.

An Azure region is a geographic area containing one or more datacenters (e.g., "Central India"). Availability Zones are physically separate datacenters within a region, each with independent power, cooling, and networking. Deploying resources across zones gives high availability against datacenter-level failures.
