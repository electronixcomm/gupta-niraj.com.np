Cisco Networking Labs — Command Cheat Sheet

One flow, from a blank device to NAT, plus wipe and password recovery

Same stage order as the Practice Checklist. All commands start from enable → configure terminal unless noted.

Switch> enable
Switch# configure terminal
Switch(config)#

Necessity key: Required = does not work without it; Recommended = good practice; Verify = check command; Optional = situational.

Stage 0. Start clean

Switch# erase startup-config          ! same as: write erase
Switch# delete flash:vlan.dat         ! switches only: VLAN database
Switch# reload                        ! answer "no" to save; "no" to setup dialog
  • erase startup-config does not change the running config; it takes effect at reload.
  • If asked "System configuration has been modified. Save?" answer no, or you restore what you just erased.
  • There is no single command for everything; this three-command sequence is the closest. Verify with show startup-config ("startup-config is not present").

Stage 1. Build, cable, address [Lab 1]

Link Cable
End device to switch Copper straight-through
Switch–switch, router–router, PC–PC Copper cross-over
PC to console Rollover
Serial DCE/DTE; clock rate on DCE only 
PC> ipconfig /all
PC> arp -a
Switch# show mac address-table

The first ping often drops one packet while ARP resolves.

Stage 2. Hostname, banners, saving

SW1(config)# hostname SW1
SW1(config)# no ip domain-lookup
SW1(config)# banner motd #Authorized Access Only#
SW1(config)# banner login #Please enter your credentials#
SW1(config)# banner exec #Welcome to SW1#
SW1# copy running-config startup-config     ! or: write memory

# is the delimiter; use any character not in your message. Order shown at login: MOTD, login banner, credentials, exec banner.

Stage 3. Console and privileged mode

SW1(config)# line console 0
SW1(config-line)# password Cisco123
SW1(config-line)# login
SW1(config-line)# logging synchronous
SW1(config-line)# exec-timeout 5 0
SW1(config)# enable secret StrongPass1
SW1(config)# service password-encryption
  • enable password is legacy plaintext; if both exist the secret wins. Keep only the secret.
  • Type 7 (service password-encryption) is reversible; type 5 (enable secret, username ... secret) is an MD5 hash.

Stage 4. VTY baseline and management address

SW1(config)# line vty 0 15
SW1(config-line)# password Cisco123
SW1(config-line)# login
SW1(config)# interface vlan 1
SW1(config-if)# ip address 192.168.1.10 255.255.255.0
SW1(config-if)# no shutdown
SW1(config)# ip default-gateway 192.168.1.1

Telnet cannot work until the SVI has an IP and is up.

Stage 5. SSH

SW1(config)# ip domain-name uniglobe.com.np
SW1(config)# username admin privilege 15 secret AdminPass1
SW1(config)# crypto key generate rsa general-keys modulus 2048
SW1(config)# ip ssh version 2
SW1(config)# line vty 0 15
SW1(config-line)# login local
SW1(config-line)# transport input ssh
SW1(config)# ip ssh time-out 60
SW1(config)# ip ssh authentication-retries 3
PC> ssh -l admin 192.168.1.10
  • Hostname and domain name must exist before the RSA keys.
  • login local ignores the line password; a user without privilege 15 lands at > and must type enable.
  • Change transport input from the console, never from the VTY session you are using.
Telnet SSH
TCP port 23 22
Encrypted No Yes
Needs VTY login Hostname, domain, RSA keys, local user

Stage 6. Port hygiene

SW1(config)# interface fa0/1
SW1(config-if)# description PC0
SW1(config)# interface range fa0/4 - 24
SW1(config-if-range)# shutdown

Stage 7. VLANs [Labs 3A, 3B, 7]

SW1(config)# vtp mode transparent
SW1(config)# vlan 10
SW1(config-vlan)# name Sales
SW1(config)# interface range fa0/1 - 10
SW1(config-if-range)# switchport mode access
SW1(config-if-range)# switchport access vlan 10
SW1(config)# no vlan 30                   ! deletes the VLAN
SW1# show vlan brief
SW1# show vlan id 10

Ports of a deleted VLAN stay assigned and show inactive; they do not return to VLAN 1.

Stage 8. Trunks

SW1(config)# interface gi0/1
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk native vlan 999
SW1(config-if)# switchport trunk allowed vlan 10,20,100
SW1# show interfaces trunk
SW1# show interfaces gi0/1 switchport

Native VLAN must match on both ends or CDP reports a native VLAN mismatch.

Stage 9. Router-on-a-stick + DHCP relay [Lab 3B]

Router(config)# interface g0/0/0
Router(config-if)# no shutdown                      ! parent has no IP
Router(config)# interface g0/0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.1.1 255.255.255.0
Router(config-subif)# ip helper-address 172.16.100.2
  • The helper converts the client broadcast to a unicast and writes the subinterface address (giaddr); the server picks the pool from it.
  • No DHCP address: check trunk allowed list, dot1Q ID, helper address, server gateway and a pool per subnet.

Stage 10. Layer 3 switch (SVIs) [Lab 3A]

SW1(config)# ip routing
SW1(config)# interface vlan 10
SW1(config-if)# ip address 192.168.1.1 255.255.255.0
SW1(config-if)# no shutdown
SW1(config)# interface fa0/24
SW1(config-if)# no switchport                        ! routed uplink
SW1(config-if)# ip address 10.0.0.1 255.255.255.252

An SVI is up/up only if its VLAN exists and has at least one active port.

Router-on-a-stick Layer 3 switch
Link 802.1Q trunk to router None
Gateway Subinterface SVI
Key commands encapsulation dot1Q ip routing, interface vlan

Stage 11. Router links and static routing [Lab 4]

Router(config)# interface s0/0/0
Router(config-if)# ip address 10.0.2.1 255.255.255.252
Router(config-if)# clock rate 64000                   ! DCE end only
Router(config-if)# no shutdown
Router(config)# ip route 192.168.3.0 255.255.255.0 10.0.12.2         ! AD 1
Router(config)# ip route 192.168.3.0 255.255.255.0 10.0.12.6 100     ! floating
Router(config)# ip route 0.0.0.0 0.0.0.0 172.31.0.1                  ! default
Source AD
Connected 0
Static 1
OSPF 110
RIP 120
Floating static (lab values) 10, 100, 200

A floating route appears only when the AD 1 route disappears. A next hop that is not on a connected network is never installed.

Stage 12. RIPv2 [Lab 5]

Router(config)# router rip
Router(config-router)# version 2
Router(config-router)# no auto-summary
Router(config-router)# network 10.0.0.0
Router(config-router)# passive-interface g0/2          ! LAN ports only
Router(config-router)# default-information originate   ! edge router only
Router(config-router)# redistribute static

network takes classful networks. Never make a router-to-router link passive. A hop count of 16 means unreachable.

Stage 13. OSPF [Lab 6]

Router(config)# router ospf 10
Router(config-router)# router-id 1.1.1.1
Router(config-router)# network 10.0.1.0 0.0.0.3 area 0
Router(config-router)# passive-interface g0/2
Router(config-router)# default-information originate
Router(config-router)# redistribute static subnets
Router(config-router)# auto-cost reference-bandwidth 1000     ! same on every router
Router(config-if)# ip ospf cost 1                              ! both ends
Router# clear ip ospf process                                  ! after a router-id change
Prefix Wildcard
/30 0.0.0.3
/24 0.0.0.255

Neighbour mismatches: area ID, stub flag, authentication, Hello/Dead timers; also subnet, wildcard, passive interface. DR election: priority, then router ID, 0 never; point-to-point links elect none.

Stage 14. STP, port security, EtherChannel [Lab 7]

SW1(config)# spanning-tree vlan 99,110,120 root primary       ! 24576 + VLAN
SW2(config)# spanning-tree vlan 99,110,120 root secondary     ! 28672 + VLAN
SW1(config)# spanning-tree mode rapid-pvst
SW1(config-if)# spanning-tree portfast
SW1(config-if)# spanning-tree bpduguard enable
SW1(config-if)# switchport port-security
SW1(config-if)# switchport port-security maximum 1
SW1(config-if)# switchport port-security mac-address sticky
SW1(config-if)# switchport port-security violation shutdown    ! or restrict / protect
SW1(config-if)# switchport port-security aging time 10
SW1(config-if)# switchport port-security aging type inactivity
SW1(config)# interface range gi0/1 - 2
SW1(config-if-range)# channel-group 1 mode active              ! other side: passive
SW1(config)# interface port-channel 1
SW1(config-if)# switchport mode trunk
Violation mode Port Log Counter
shutdown err-disabled Yes Yes
restrict Up Yes Yes
protect Up No No
  • Recover err-disabled: fix the cause, then shutdown / no shutdown.
  • LACP forms with active/active or active/passive; passive/passive shows (I); a mismatch shows (s); good bundle Po1(SU) with members (P).
  • PortFast on device ports only, always with BPDU Guard. Root bridge has no root port. PVST+ outage about 30 s, Rapid PVST+ about one lost ping.

Stage 15. HDLC, PPP, CHAP [Lab 8]

Router(config-if)# clock rate 128000                  ! DCE end
Router(config-if)# encapsulation ppp
Router(config-if)# ppp authentication chap
Router(config)# username HQ password Cisco123          ! the OTHER router's hostname
Router# debug ppp authentication
Router# undebug all

HDLC is the default; a PPP/HDLC mismatch gives up, line protocol down. Good result: Encapsulation PPP, LCP Open.

Stage 16. ACLs [Lab 8]

Router(config)# ip access-list standard NO-GUEST
Router(config-std-nacl)# deny host 192.168.10.20
Router(config-std-nacl)# permit any
Router(config)# interface g0/0
Router(config-if)# ip access-group NO-GUEST out
Router(config)# access-list 5 permit host 192.168.20.10
Router(config)# line vty 0 4
Router(config-line)# access-class 5 in
Router(config)# ip access-list extended BRANCH-IN
Router(config-ext-nacl)# permit tcp 192.168.10.0 0.0.0.255 host 192.168.20.100 eq www
Router(config-ext-nacl)# permit icmp 192.168.10.0 0.0.0.255 host 192.168.20.100 echo
Router(config-ext-nacl)# deny ip 192.168.10.0 0.0.0.255 192.168.20.0 0.0.0.255
Router(config-ext-nacl)# permit ip any any

Standard: source only, place near the destination. Extended: source, destination and port, place near the source. Top-down, first match wins, implicit deny at the end.

Stage 17. NAT / PAT [Lab 8]

Router(config)# interface g0/0
Router(config-if)# ip nat inside
Router(config)# interface s0/0/1
Router(config-if)# ip nat outside
Router(config)# ip nat inside source static 192.168.20.100 209.165.200.229
Router(config)# access-list 1 permit 192.168.10.0 0.0.0.255
Router(config)# ip nat inside source list 1 interface s0/0/1 overload

overload = PAT. The ISP does not route private addresses, so the internet cannot ping 192.168.20.100.

Stage 18. Hardening

Router(config)# service password-encryption
Router(config-if)# no cdp enable                       ! on the ISP link
Router(config-if)# ip access-group OUTSIDE-IN in       ! deny private sources, permit ip any any

Stage 20. Save, back up, wipe, recover

SW1# copy running-config startup-config      ! or: write memory
SW1# copy running-config tftp                ! backup, if a TFTP server exists
SW1# show running-config

Wipe in one go

Router# erase startup-config
Router# reload                               ! answer "no" to save
Switch# erase startup-config
Switch# delete flash:vlan.dat
Switch# reload

Verify: show startup-config reports it is not present, and the initial configuration dialog appears (answer no).

Forgot the password: router (ROMMON, Cisco ISR family)

(power cycle; send Break within about 60 s: Ctrl+Break in a terminal program)
rommon 1 > confreg 0x2142              ! ignore the saved config at boot
rommon 2 > reset
Router> enable                         ! no password; answer "no" to setup dialog
Router# copy startup-config running-config     ! restores the old config
Router# configure terminal
Router(config)# enable secret NewPass1
Router(config)# interface g0/0
Router(config-if)# no shutdown                  ! interfaces come back shut; repeat for each
Router(config)# config-register 0x2102          ! back to normal boot
Router(config)# end
Router# copy running-config startup-config
Router# reload
Router# show version                            ! "Configuration register is 0x2102"
  • Order matters: copy startup into running first. Saving first overwrites your real config with a blank one.
  • Packet Tracer: a Ctrl+C during boot is commonly used instead of Break; check your version.

Forgot the password: switch (Catalyst 2960 family)

(hold the Mode button, power on, release when the SYSTEM LED changes; prompt "switch:")
switch: flash_init
switch: load_helper
switch: dir flash:
switch: rename flash:config.text flash:config.text.old
switch: boot
Switch> enable                         ! answer "no" to the setup dialog
Switch# rename flash:config.text.old flash:config.text
Switch# copy flash:config.text system:running-config
Switch# configure terminal
Switch(config)# enable secret NewPass1
Switch(config)# end
Switch# copy running-config startup-config
  • Mode-button timing differs by model; follow Cisco's guide for yours.
  • I believe Packet Tracer does not simulate the Mode-button procedure on switches; practise router recovery there and switch recovery on real hardware.
  • no service password-recovery disables this method; the only way back is a full wipe, which erases the config.
  • Recovery requires physical console access, which is why physical security matters. Use it only on equipment you own or are authorised to manage.

Lands at > after SSH User lacks privilege 15 enable or fix the username

Stub network missing redistribute static subnets missing show ip protocols

EtherChannel not forming passive/passive, speed mismatch show etherchannel summary

Memory aids

  • OSPF wildcard: block size minus one (/30 = 0.0.0.3, /24 = 0.0.0.255).
  • OSPF neighbour mismatches: Area, Stub flag, Authentication, Hello/Dead timers.
  • Floating static: give the backup a higher AD than the primary and the protocol in use.
  • Recovery register: 0x2142 skips the config, 0x2102 is normal.
  • Save after every stage; changes live only in RAM until saved.

Common gotchas

  • clock rate goes on the DCE end only.
  • network in RIP is classful; in OSPF it is subnet plus wildcard.
  • Router interfaces need no shutdown; switch ports are up by default.
  • redistribute static in OSPF needs subnets.
  • ACL order matters: specific permits above the deny, and mind the implicit deny.
  • ip nat inside is needed on the branch-facing serial, or branch traffic is not translated.
  • Sticky MAC addresses are lost on reload unless saved.
  • Turn debugging off with undebug all.
  • Never change transport input on the VTY line you are logged in on.
  • Never save the config before restoring it during password recovery.
