Lab 1 · Simple LAN

Build the LAN, address it, prove it works

Which cable type joins a PC, server or printer to the switch, and when do you use a cross-over?

Copper straight-through for end device to switch. Use cross-over for like devices (switch to switch, router to router, PC to PC). Rollover is only for console.

How do you give PC0 a static address and what must you leave blank in this lab?

Desktop > IP Configuration > Static: 192.168.1.2 with mask 255.255.255.0. Leave the gateway blank, because there is no router in this LAN.

Which command on the PC shows its own IP and MAC?

Run it in the Command Prompt.

ipconfig /all
How do you list the IP-to-MAC mappings the PC has learned?

Ping a host first so ARP has something to store.

arp -a
Which switch command proves the switch learned all four devices?

Expect four dynamic entries, one per port Fa0/1–Fa0/4, after pings.

show mac address-table

Verify it

Healthy output and what each fault looks like

Condition: every ping works. What does a healthy result look like?

4 replies, 0% loss. The first ping may time out while ARP resolves; that is normal.

ping 192.168.1.3
Condition: one host does not answer. What do you check, in order?

1) link light/cable type, 2) IP and mask on that PC (ipconfig /all), 3) the switch port status.

ipconfig /all
show interfaces status
show ip interface brief
Condition: show mac address-table lists only two of four devices. Why?

Switches learn a MAC only after the device sends a frame. Ping from the silent devices and re-check.

show mac address-table
Condition: two PCs cannot reach each other but both reach the server. What is a likely cause?

A wrong subnet mask or a duplicate/typo IP on one PC. Compare IP and mask on both.

ipconfig /all
Professional practice

Rename every device exactly as the lab states and save a .pkt after each stage. A saved checkpoint lets you undo a bad change in seconds.

Which two commands protect privileged mode and obscure line passwords?

enable secret is a hash; service password-encryption only obscures (type 7, reversible).

How do you give the switch a management address?

The SVI must be no shutdown, and the gateway lets the switch answer other subnets.

What is the full SSH sequence, and why is the order important?

Hostname and domain name must exist before the RSA keys, because the key name is built from them.

crypto key generate rsa general-keys modulus 2048
ip ssh version 2
line vty 0 15
 login local
 transport input ssh

Units 2 and 3 · Switch fundamentals

Banners, passwords, Telnet, SSH, VLAN housekeeping, routed ports, backup

Which three banners exist, and in what order do they appear at login?

MOTD first, then the login banner, then credentials, then the exec banner after a successful login. # is only the delimiter; use any character not in the message.

banner motd #Authorized Access Only#
banner login #Please enter your credentials#
banner exec #Welcome to SW1#
What is the difference between enable password and enable secret?

enable password is stored in plaintext (legacy). enable secret is hashed (type 5) and wins if both exist. Keep only the secret.

enable secret StrongPass1
What does service password-encryption actually do?

It obscures line and enable password entries as type 7, which is reversible. It does not make secrets stronger.

service password-encryption
Why does Telnet fail before the management SVI is configured?

The switch has no IP address to connect to yet. Once interface vlan 1 has an IP and no shutdown, Telnet works with the VTY password until you set transport input ssh.

interface vlan 1
 ip address 192.168.1.10 255.255.255.0
 no shutdown
How do you set the SSH timeout and failed-login limit?
ip ssh time-out 60
ip ssh authentication-retries 3
How do you assign a range of ports to a VLAN in one go?
interface range fa0/2 - 5
 switchport mode access
 switchport access vlan 20
You delete a VLAN that still has ports. What happens to those ports?

They stay assigned to the deleted VLAN and become inactive. They do not move back to VLAN 1. Reassign them.

no vlan 30
show interfaces fa0/1 switchport
How do you turn a Layer 3 switch port into a routed port?

The port stops switching and gets an IP address like a router interface. Needs ip routing for inter-VLAN routing elsewhere.

interface fa0/24
 no switchport
 ip address 10.0.0.1 255.255.255.252
Which command tells you at a glance whether a port is access or trunk and which VLAN?
show interfaces fa0/1 switchport
show interfaces status
How do you view a filtered MAC table, and how do you clear it?
show mac address-table dynamic
show mac address-table interface fa0/1
show mac address-table vlan 10
clear mac address-table dynamic
How do you confirm the physical topology matches the plan?

CDP is Cisco-only; LLDP is the open standard.

show cdp neighbors
show cdp neighbors detail
show lldp neighbors
How do you back up and save the configuration?

write memory is shorthand for copy running-config startup-config; TFTP needs a reachable server.

copy running-config startup-config
write memory
copy running-config tftp
Compare router-on-a-stick and a Layer 3 switch for inter-VLAN routing.

Router-on-a-stick needs a trunk and subinterfaces and shares one link; a Layer 3 switch uses ip routing and SVIs with no external router, scales better and is faster.

The secret shows as type 5 ($1$...) and line passwords as type 7.

Lab 3A · Layer 3 switch

How do you create VLAN 10 and put Fa0/1–3 in it?
vlan 10

interface range fa0/1 - 3
 switchport mode access
 switchport access vlan 10
Which command makes the 3560 route between VLANs?

Without it SVIs exist but traffic does not cross.

ip routing
How do you create the gateway for VLAN 10 and VLAN 20?
interface vlan 10
 ip address 192.168.1.1 255.255.255.0

interface vlan 20
 ip address 192.168.2.1 255.255.255.0

An SVI shows up/down. What do you check?

The SVI is up only if the VLAN exists and at least one port in it is active.

show vlan brief
show ip interface brief
How should the DHCP servers be set up?

Static IP (.2) with the SVI as gateway, DHCP service On, start address .10, mask /24, max users 50.

What should tracert from Laptop1 to Laptop3 show?

The first hop is the SVI of the source VLAN (192.168.1.1), then the destination.

tracert 192.168.2.10

Connected C routes for 192.168.1.0/24 and 192.168.2.0/24 via Vlan10 and Vlan20.

show ip route
Condition: SVI shows up/up, up/down, or administratively down. Meaning?

up/up is healthy. up/down means the VLAN is missing or has no active port. Administratively down means you forgot no shutdown.

show ip interface brief

One hop through the source VLAN's SVI (192.168.1.1), then the destination.

tracert 192.168.2.10

Lab 3B · VLANs, trunks, router-on-a-stick

Trunk to the router, build subinterfaces, relay DHCP

How do you build the trunk to the router and limit its VLANs?
interface gi0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,100
What does the router parent interface need?

Only no shutdown. The IP addresses go on subinterfaces.

interface g0/0/0
 no shutdown
How do you create the VLAN 10 gateway on a subinterface?
interface g0/0/0.10
 encapsulation dot1Q 10
 ip address 192.168.1.1 255.255.255.0
Where do you point DHCP clients to the remote server and why?

The helper turns the broadcast into a unicast and stamps the subinterface address (giaddr) so the server picks the right pool.

interface g0/0/0.10
 ip helper-address 172.16.100.2
Laptops get no address. List the first four checks.

1) trunk allows the VLAN, 2) dot1Q ID matches, 3) helper address on client subinterface, 4) server gateway and a pool per subnet.

show interfaces trunk
show ip interface brief
Which command shows VLANs and trunk status quickly?
show vlan brief
show interfaces trunk

Gi0/1 in trunking mode, native VLAN 1, allowed and active VLANs 10, 20 and 100.

show interfaces trunk
Healthy: what does the router show for subinterfaces?

Each subinterface up/up. If the parent is down, every subinterface is down.

show ip interface brief
Condition: a laptop shows 169.254.x.x. Which settings do you check?

Trunk allowed list, dot1Q ID, ip helper-address on that subinterface, and the server's gateway and pool.

show interfaces trunk

Healthy: what addresses should laptops receive?

192.168.1.x for VLAN 10 and 192.168.2.x for VLAN 20, gateway = the subinterface address.

tracert 172.16.100.2

Add description to every trunk and subinterface, and keep a VLAN plan table. Prune unneeded VLANs from trunks; it is a basic security habit.

Lab 4 · Static and default routes

Address links, add primary and floating routes, test failover

Why use /30 networks on router-to-router links?

They use exactly two usable hosts, wasting no address space.

How do you add a normal static route and a floating backup?

The backup has a higher AD, so it appears in the table only when the primary route disappears.

ip route 192.168.3.0 255.255.255.0 10.0.12.2
ip route 192.168.3.0 255.255.255.0 10.0.12.6 100
How do you configure a default route?
ip route 0.0.0.0 0.0.0.0 10.0.12.2
How do you list only the static routes?
show ip route static
How do you test failover cleanly?

Keep ping -t running on a PC, shut the primary link, watch the path change, then restore it.

interface g0/0/1
 shutdown
! test, then
 no shutdown
Why can two default routes via the transit router cause a loop?

During failover each router can send traffic back to the other. Specific routes per LAN are safer.

Verify it

Healthy output and what each fault looks like

Healthy: what does show ip route static show with all links up?

Static routes S with [1/0] via the primary next hop. The floating route is hidden.

show ip route static
Condition: after you shut the primary link, what should appear?

The floating route S ... [100/0] via the backup next hop, and pings keep working.

show ip route static
ping -t 192.168.3.10
Condition: you shut the link but the primary route stays. Why?

The next-hop interface is still up (for example via a switch), so the route is not withdrawn.

show ip interface brief
Healthy: how do you prove the path changed?

tracert shows a different hop before and after the shutdown.

tracert 192.168.3.10
Condition: ping works one way only. What is missing?

A return route on the far router. Test from both ends.

show ip route
ping 192.168.1.1
Professional practice

Change one thing at a time and re-test. Always undo a test shutdown before you move on; forgotten shutdowns are a classic cause of hours of confusion.

Lab 5 · RIPv2

Cable WAN links, run RIP, control it, default route

What is required before routers have serial ports?

Power off, add an HWIC-2T, power on. Then set clock rate 64000 on the DCE end only.

interface s0/0/0
 clock rate 64000
 no shutdown
Give the minimum RIPv2 configuration.

network takes classful networks only.

router rip
 version 2
 no auto-summary
 network 10.0.0.0
 network 172.16.0.0
Why is no auto-summary needed here?

172.16.20.0/24 and 172.16.50.0/24 are separated by 10.x networks, so summarising breaks routing.

How do you stop RIP updates on a LAN port?

Do this only on LAN ports, never on router-to-router links.

router rip
 passive-interface g0/2
How do you create a default route and share it through RIP?

The floating default has AD 200 as a backup.

ip route 0.0.0.0 0.0.0.0 172.31.0.1
ip route 0.0.0.0 0.0.0.0 172.31.0.5 200
router rip
 default-information originate
How does a router with a non-RIP stub (Butwal) get shared?

BR-B holds a static route and redistributes it.

ip route 192.168.30.0 255.255.255.0 10.0.4.2
router rip
 redistribute static
Which commands verify RIP?
show ip protocols
show ip route rip
show ip route
What do you expect for the default route after the ISP link goes down?

The floating route appears: S* 0.0.0.0/0 [200/0] via 172.31.0.5.

Lab 6 · OSPF single area

Set router IDs, join OSPF, share routes, tune cost, fix faults

How do you start OSPF with a fixed router ID?

The router ID wins over loopback and interface addresses.

router ospf 10
 router-id 1.1.1.1
How do you advertise 10.0.1.0/30 and a /24 LAN?

Use the subnet plus a wildcard mask.

network 10.0.1.0 0.0.0.3 area 0
network 172.16.20.0 0.0.0.255 area 0
What are the wildcards for /30 and /24?

Invert the mask: /30 is 0.0.0.3 and /24 is 0.0.0.255.

How do you advertise a LAN but send no Hellos?
passive-interface g0/2
How do you share the default route and a static route?

subnets is needed so subnetted routes are redistributed.

default-information originate
redistribute static subnets
Which commands verify neighbours and routes?

Expect five FULL adjacencies; point-to-point links show FULL/ -.

show ip ospf neighbor
show ip route ospf
show ip ospf interface g0/0
show ip ospf database
show ip protocols
How do you change cost and keep the network consistent?

Set the cost on both ends; the reference bandwidth must match on every router.

interface s0/0/0
 ip ospf cost 1
router ospf 10

An OSPF router ID change does not take effect. What now?
clear ip ospf process
No neighbour forms. What do you check?

Area ID, stub flag, authentication, Hello/Dead timers, subnet and wildcard, passive interface.

Lab 7 · STP, port security, EtherChannel

Build the VLAN base, shape STP, harden ports, bundle links

How do you stop VLAN syncing and create the VLANs?

Do it on every switch.

vtp mode transparent
vlan 110
 name LTE_DATA
How do you build a trunk with an unused native VLAN?

A mismatch gives a CDP native VLAN warning.

interface range fa0/1 - 2
 switchport mode trunk
 switchport trunk native vlan 999
How do you make CORE-SW1 the root and SITE-B the backup?

Priority becomes 24576+VLAN and 28672+VLAN.

spanning-tree vlan 99,110,120,130,140,210,310,320,999 root primary
spanning-tree vlan 99,110,120,130,140,210,310,320,999 root secondary
Which mode gives fast convergence?

About one lost ping instead of about 30 seconds.

spanning-tree mode rapid-pvst
How do you protect a device port from rogue switches?

Use on device ports only, never on trunks.

spanning-tree portfast
spanning-tree bpduguard enable
How do you recover an err-disabled port?

Fix the cause first.

shutdown
no shutdown
show interfaces status err-disabled

switchport port-security

How do you build an LACP EtherChannel?

One side active, the other active or passive.

interface port-channel 1

Po1(SU) with members (P) is good; (I) means stand-alone, (s) suspended.

Lab 8 · PPP/HDLC, ACLs, NAT

Bring up WAN links, filter traffic, translate addresses, harden

Which serial cable end gets the clock?

DCE only: clock rate 128000. Click the router that should be DCE first when cabling.

interface s0/0/0
 clock rate 128000
The serial line is up but the protocol is down. Why?

Most often a PPP/HDLC mismatch. HDLC is the default.

show interfaces serial 0/0/0
How do you configure PPP with CHAP?

The username is the other router's hostname; passwords match on both ends.

interface s0/0/0
 encapsulation ppp
 ppp authentication chap
username HQ password Cisco123
How do you watch CHAP and then stop?
debug ppp authentication
undebug all
Block one guest PC with a standard ACL.

Standard ACLs match source only, so place them near the destination.

ip access-list standard NO-GUEST
 deny host 192.168.10.20
 permit any
interface g0/0
 ip access-group NO-GUEST out
Restrict Telnet/SSH to one admin PC.
access-list 5 permit host 192.168.20.10
line vty 0 4
 access-class 5 in
Write an extended ACL that allows web and ping to the server only.

Extended ACLs go near the source. End with permit ip any any if you do not want the implicit deny.

ip access-list extended BRANCH-IN
 permit tcp 192.168.10.0 0.0.0.255 host 192.168.20.100 eq www
 permit icmp 192.168.10.0 0.0.0.255 host 192.168.20.100 echo
 deny ip 192.168.10.0 0.0.0.255 192.168.20.0 0.0.0.255
 permit ip any any
interface g0/0
 ip access-group BRANCH-IN in
How do you check an ACL is matching?

Counters rise as traffic hits each line.

show access-lists
Which interfaces get NAT roles?

Inside: LAN and the branch-facing serial. Outside: the ISP link.

interface g0/0
 ip nat inside
interface s0/0/0
 ip nat inside
interface s0/0/1
 ip nat outside
Publish the server and give everyone internet access.

Static NAT for the server; PAT with overload for hosts.

ip nat inside source static 192.168.20.100 209.165.200.229
access-list 1 permit 192.168.10.0 0.0.0.255
access-list 1 permit 192.168.20.0 0.0.0.255
ip nat inside source list 1 interface s0/0/1 overload
Which commands verify NAT and reset the table?
show ip nat translations
show ip nat statistics
clear ip nat translation *
Name three hardening steps from the final stage.

Encrypt passwords, stop advertising CDP to the ISP, and block private source addresses on the outside port.

service password-encryption
interface s0/0/1
 no cdp enable
 ip access-group OUTSIDE-IN in

up, line protocol is up, Encapsulation PPP, LCP Open, Open: IPCP. For HDLC: Encapsulation HDLC.

show interfaces serial 0/0/0
Condition: up, line protocol is down. Causes?

Encapsulation mismatch (PPP vs HDLC), CHAP failure, or missing clock rate on the DCE end.

show interfaces serial 0/0/0
show controllers serial 0/0/0
debug ppp authentication
Condition: the interface shows down/down. What first?

Cable not attached or other end shut. Check cabling and no shutdown at both ends.

show ip interface brief
Healthy: how do you confirm an ACL is applied and in which direction?

The interface output names it, for example "Outgoing access list is NO-GUEST".

show ip interface g0/0
Healthy: how do you prove an ACL line matched?

Match counters increase after you test.

show access-lists
Condition: expected traffic is blocked. What common mistake?

A broad deny above a specific permit, wrong direction (in vs out), or the implicit deny at the end.

show access-lists
show ip interface g0/0
Healthy: what does show ip nat translations show?

Inside local (private) mapped to inside global (public), with ports for PAT and a permanent entry for static NAT.

show ip nat translations
Condition: no translations appear. Why?

ip nat inside/outside roles missing or wrong, ACL 1 does not match the hosts, or no traffic yet.

show ip nat statistics
show running-config | include nat
Expected: can INTERNET-SRV ping the private server 192.168.20.100?

No. The ISP does not route private addresses. It can reach the published address (209.165.200.229).

ping 209.165.200.229
Healthy: after hardening, is everything still working?

Re-run the earlier tests: internal pings, NAT, ACL five-test table, and check show cdp neighbors on the ISP link.

show cdp neighbors
show access-lists
Professional practice

Name your ACLs and add remarks, test with a five-case table, and read the counters. On real devices, schedule reload in 5 before editing an ACL remotely so a mistake rolls back; always keep a backup of the config.

Wipe and password recovery

Start clean, and get back into a device you are locked out of

How do you wipe a router's configuration so it starts blank?

erase startup-config clears NVRAM; the running config only changes at reload. Answer no if asked to save.

erase startup-config
reload
Why does a switch need one more command to be fully wiped?

VLANs are stored in flash:vlan.dat, not in startup-config, so they survive an erase.

erase startup-config
delete flash:vlan.dat
reload
Is there a single command that wipes everything in one go?

No. The closest is the short sequence: erase startup-config, (switch) delete vlan.dat, reload.

You reload after erase startup-config and see "System configuration has been modified. Save?". What do you answer and why?

no. Answering yes writes the running config back and undoes the wipe.

You forgot the enable password on a router. How do you get in (overview)?

Break into ROMMON, set the config register to ignore the saved config, boot, restore the config, set a new password, then restore the register.

Which ROMMON commands skip the saved configuration on the next boot?

confreg 0x2142 makes the router ignore startup-config; reset reboots it.

rommon 1 > confreg 0x2142
rommon 2 > reset
After booting with register 0x2142, what exactly do you type to restore the config and set a new password?

Copy startup into running, not the other way around. Interfaces come back shut, so enable them.

Router> enable
Router# copy startup-config running-config
Router# configure terminal
Router(config)# enable secret NewPass1
Router(config)# interface g0/0
Router(config-if)# no shutdown
What do you do last so the router boots normally next time?

Set the register back to 0x2102, save, and reload.

config-register 0x2102
copy running-config startup-config
reload
Why must you never run copy running-config startup-config before restoring?

The running config is blank at that point; saving would overwrite your real saved configuration with nothing.

How is password recovery on a Catalyst 2960 switch different?

Use the Mode button at power-on to reach switch:, then rename config.text so the switch boots without it.

switch: flash_init
switch: load_helper
switch: rename flash:config.text flash:config.text.old
switch: boot
After the switch boots, how do you restore the config and set a new password?
Switch> enable
Switch# rename flash:config.text.old flash:config.text
Switch# copy flash:config.text system:running-config
Switch# configure terminal
Switch(config)# enable secret NewPass1
Switch(config)# end
Switch# copy running-config startup-config
What stops password recovery, and what is then the only way back in?

no service password-recovery disables the procedure. The only option is a full wipe, which erases the config.

Can you practise this in Packet Tracer?

Router recovery is usually possible (a Ctrl+C at boot is commonly used). I believe the switch Mode-button procedure is not simulated, so practise that on real hardware; check your version.

Verify it

Healthy output and what each fault looks like

Healthy: how do you prove a device is wiped?

show startup-config says it is not present; after reload the initial configuration dialog appears; the running config is default.

show startup-config
show running-config
Condition: after a switch wipe, old VLANs still exist. Why?

flash:vlan.dat was not deleted.

show vlan brief
delete flash:vlan.dat
Condition: after erase startup-config and reload the old config returned. Why?

You answered yes to "Save?" and wrote it back, or the wipe ran on the wrong device.

show startup-config
Healthy: what does show version show during recovery?

"Configuration register is 0x2142 (will be 0x2102 at next reload)" while recovering; 0x2102 when finished.

show version
Condition: after recovery the router works but interfaces are down. Why?

Interfaces come back shut when the config is restored on a blank boot. Use no shutdown on each.

show ip interface brief
Condition: the router boots into setup dialog every time. Why?

The register is still 0x2142 (config ignored). Set config-register 0x2102, save, reload.

show version
Healthy: how do you confirm the new password works?

Reload, log out and in; the old password fails, the new secret works.

Condition: the switch will not accept the Mode-button method. What may be the reason?

no service password-recovery is configured, or the model uses a different timing/procedure.

Professional practice

Back up the configuration before recovery or wipe, record who is authorised, and keep passwords in a secure store, not on paper at the rack. Recovery needs physical console access, so protect the room as well as the device. Use it only on equipment you are authorised to manage.

Professional practice for every lab

Habits that apply at every stage

  • Before every change. Back up the running config, write down what you intend to change and how you will verify it.
  • While changing. Change one thing, verify with a show or ping, and only then continue.
  • After every change. Save with copy running-config startup-config and note the result.
  • Troubleshooting order. Physical, interface (show ip interface brief), VLAN or trunk, addressing, routing, then ACL or NAT.
  • Document. Record both what broke and what you found; add recommendations for next time.

Reading output in any condition

Good, bad and partial results

show ip interface brief: what do the Status/Protocol pairs mean?

up/up is working. up/down means Layer 1 is fine but Layer 2 failed (encapsulation, keepalives, no clock). down/down means cable or far end. administratively down means shut; use no shutdown.

show ip interface brief
What do ping results tell you?

! or Reply = success. . or Request timed out = no reply (route, ARP, ACL, or firewall). U or Destination host unreachable = a router has no route. First-packet loss is usually ARP.

ping 10.0.1.1
What does tracert tell you when it stops?

The last responding hop is the last good device; the fault is at or just beyond the next hop (missing route, ACL or down link).

tracert 192.168.3.10
Which route codes should you recognise?

C connected, L local, S static, S* default static, R RIP, O OSPF, O*E2 default via OSPF, E2 external type 2. The number in brackets is [AD/metric].

show ip route
How do you find where a command lives in the config?

Filter the output with begin, include or section.

show running-config | section router ospf
show running-config | include nat
What is a quick end-to-end verification routine?

Interface, VLAN/trunk, addressing, route, neighbour, then ACL/NAT, using the show commands in that order; finish with ping and traceroute.
