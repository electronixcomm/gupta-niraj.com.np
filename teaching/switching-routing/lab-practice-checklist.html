Cisco Networking Labs — Practice Checklist

One flow, from a blank device to NAT, plus wipe and password recovery

Work top to bottom on Packet Tracer (or real gear). After every step run the show / ping check written beside it before you continue. Lab references in brackets show where each stage appears in the lab series.

Stage 0. Start clean (do this before every lab)

Stage 1. Build, cable, address a simple LAN [Lab 1]

Stage 2. Hostname, banners, saving [Lab 2 / Unit 2]

Stage 3. Console and privileged mode

Stage 4. VTY baseline and management address

Stage 5. SSH [Lab 2]

Stage 6. Port hygiene

Stage 7. VLANs [Labs 3A, 3B, 7]

Stage 8. Trunks

Stage 9. Inter-VLAN routing: router-on-a-stick + DHCP relay [Lab 3B]

Stage 10. Inter-VLAN routing: Layer 3 switch [Lab 3A]

Stage 11. Router links and static routing [Lab 4]

Stage 12. Dynamic routing: RIPv2 [Lab 5]

Stage 13. Dynamic routing: OSPF [Lab 6]

Stage 14. STP, port security, EtherChannel [Lab 7]

Stage 15. WAN links: HDLC, PPP, CHAP [Lab 8]

Stage 16. ACLs [Lab 8]

Stage 17. NAT and PAT [Lab 8]

Stage 18. Hardening [Lab 8]

Stage 19. Verification sweep (repeat after every major stage)

Stage 20. Save, back up, wipe and recover

One-sitting order: Clean start → Hostname → Banners → Console → Enable secret → VTY + SVI → SSH → Ports → VLANs → Trunks → Router-on-a-stick → L3 switch → Static routes → RIP → OSPF → STP/port security/EtherChannel → PPP/CHAP → ACL → NAT → Hardening → Verify → Save/Wipe/Recover.
