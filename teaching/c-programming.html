This section is being expanded with topic-wise MCQs covering operators, control flow, functions, pointers, and structures.

= is the assignment operator — it stores the right-hand value into the left-hand variable. == is the equality operator — it compares two values and returns 1 (true) or 0 (false). Confusing them inside an if condition is one of the most common bugs in introductory C.

An array is a contiguous block of memory holding elements of the same type — its name decays to a pointer to the first element in most expressions, but it is not a pointer. A pointer is a separate variable that stores an address. sizeof(arr) returns the total size of the array, while sizeof(ptr) returns the size of a pointer (typically 8 bytes on a 64-bit system).
